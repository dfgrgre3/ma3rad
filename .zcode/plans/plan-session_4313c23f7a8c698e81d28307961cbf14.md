# خطة جعل CeramiSys متوافقاً مع جميع الأجهزة

## المرحلة 1: واجهة متجاوبة وأجهزة لمس
- `electron/main.js`: تخفيض `minWidth/minHeight` (مثلاً 480×640) للسماح بنوافذ صغيرة.
- إضافة `src/hooks/useMediaQuery.ts` واستخدامه بدل تكرار matchMedia.
- `Sidebar.tsx`: تحويله إلى drawer منزلق (overlay) على الشاشات < lg مع زر إغلاق، بدل `w-64` الثابت.
- `PosView.tsx`: cart panel `w-[26rem]` يتحول إلى لوحة سفلية/على الشاشات الصغيرة.
- تحسين أهداف اللمس: أحجام أزرار ≥ 44px في المكونات المشتركة (`src/components/ui/`)، ودعم `touch-action` في `index.css`.
- إضافة `<meta viewport>` إن لم توجد في `index.html`.

## المرحلة 2: طباعة متعددة الأنظمة + طابعات ESC/POS متنوعة
- `electron/main.js`:
  - `print:listPrinters`: على macOS/Linux استخدام `lpstat -a`/`lp` بدل PowerShell (الاحتفاظ بمسار winspool على Windows).
  - إضافة نقل شبكي ESC/POS عبر `net.Socket` إلى المنفذ 9100 (يعمل على كل الأنظمة) بجانب المسار المحلي.
  - توحيد مجلد البيانات عبر `os.homedir()`/`app.getPath('userData')` بدل `%APPDATA%`.
- `EscPosService.ts`: إعداد عرض الطابعة 58مم/80مم (عرض 32/48 حرفاً) بدل 32 الثابت.
- `electron-builder`: إضافة targets `mac` (dmg/zip) و`linux` (AppImage/deb) — لا توجد native modules فلا إعادة بناء معقدة.
- سكربتات `electron:dist:mac` و`electron:dist:linux`.

## المرحلة 3: وصول كامل من المتصفح/الجوال عبر الشبكة المحلية
إعادة هيكلة الوصول لقاعدة البيانات (sql.js يعيش حالياً في الـrenderer فقط):
- **طبقة DB في main process**: نقل تنفيذ SQL إلى `electron/main-db.js` (sql.js في العملية الرئيسية) مع IPC عام `db:query`/`db:exec`.
- **خادم HTTP مدمج** (Node http، بدون تبعيات ثقيلة) يُشغَّل اختيارياً من الإعدادات:
  - يقدّم واجهة `dist/` ثابتة.
  - نقطة `POST /api/db/query` محمية بجلسة تسجيل دخول (bcryptjs موجود أصلاً) + توكن.
- **طبقة نقل في `DatabaseManager`** (`src/database/db.ts`): backend قابل للتبديل — IPC داخل Electron، HTTP في المتصفح — بحيث تعمل الـ44 خدمة دون تعديل منطقها (تحويل استدعاءات SQL لغير متزامن حيث يلزم).
- صفحة إعدادات جديدة لتفعيل الخادم وإظهار عنوان IP/المنفذ للاتصال من الجوال.
- شاشة دخول تعمل في المتصفح بنفس المستخدمين والأدوار الحالية (PermissionService).
