# توثيق صفحات الموارد البشرية (HR)

توثيق شامل لجميع صفحات الموارد البشرية وأقسام الموظفين في التطبيق (React + TypeScript). كل صفحة موثقة بمسارها وتفاعلاتها.

---

## `/hr/dashboard` — لوحة تحكم الموارد البشرية
- **الملف:** `src/pages/hr/hr-dashboard/HrDashboardPage.tsx`
- **الوصف:** لوحة رئيسية تعرض إحصاءات الموارد البشرية: عدد الموظفين، الرواتب الشهرية، معدل حضور اليوم، توزيع الموظفين حسب الفرع والدور الوظيفي، وسجل آخر الموظفين.
- **العناصر التفاعلية:**
  - زر «إدارة الموظفين» ← ينقل إلى `/employees`
  - زر «الحضور» ← ينقل إلى `/employees/attendance`
  - زر «التوظيف» ← ينقل إلى `/employees/recruitment` (يظهر فقط لحامل صلاحية `ui.hr.recruitment.view`)
  - أيقونة تحديث (RefreshCw) ← يعيد تحميل الإحصاءات
  - بطاقة «موظفون نشطون» ← ينقل إلى `/employees`
  - بطاقة «في إجازة» ← ينقل إلى `/employees/attendance`
  - بطاقة «موقوفون» ← ينقل إلى `/employees`
  - بطاقة «حضروا اليوم» ← ينقل إلى `/employees/attendance`
  - بطاقة «الموظفون» (بطاقة تنقل) ← `/employees`
  - بطاقة «الحضور والانصراف» ← `/employees/attendance`
  - بطاقة «الرواتب والمسحوبات» ← `/employees/payroll`
  - بطاقة «عمولات المبيعات» ← `/employees/commissions`
  - بطاقة «التوظيف والمرشحون» ← `/employees/recruitment` (مشروطة بنفس الصلاحية)

- **العناصر التفاعلية:**
  - تبويبات: «الهيكل والشواغر» / «الأقسام» / «المسميات والدرجات» / «مراكز التكلفة» / «الانتقالات» / «دورة الحياة» / «التأهيل والتسليم» / «العهد» / «تقييم الاختبار» (تظهر حسب الصلاحيات)

  - تبويب دورة الحياة: زر «تحميل» ← يجلب أحداث الموظف؛ زر «إضافة حدث» ← `addLifecycleEvent`

  - تبويب العهد: زر «تحميل»؛ زر «إرجاع» لكل عهدة مسندة ← `returnCustodyItem`؛ زر «إسناد» ← `assignCustodyItem`
  - تبويب اختبار: زر «تحميل»؛ زر «إضافة تقييم» ← `createProbationReview`

## `/hr/discipline` — الجزاءات والمخالفات والشكاوى
- **الملف:** `src/pages/hr/discipline/HrDisciplinePage.tsx`

- **العناصر التفاعلية:**
  - تبويبات: «المخالفات» / «الإنذارات» / «الجزاءات» / «الشكاوى» / «التظلمات» / «المرفقات» (بصلاحية `hr.discipline.manage`)
  - حقل «فلترة حسب معرف الموظف» + زر «تحديث» ← يعيد تحميل كل البيانات مفلترة
  - تبويب المخالفات: زر «إغلاق» على كل مخالفة غير مغلقة ← `closeViolation`؛ زر «تسجيل» ← `createViolation`

  - تبويب الشكاوى: زر «حل» على كل شكوى مفتوحة ← `resolveComplaint` (يطلب القرار عبر prompt)؛ زر «تقديم» ← `createComplaint`
  - تبويب التظلمات: على كل تظلم مفتوح: زر «قبول» / «رفض» ← `decideAppeal` (يطلب القرار عبر prompt)؛ زر «تقديم» ← `createAppeal`
  - تبويب المرفقات: زر «تحميل» ← `getAttachments` حسب نوع المرجع ومعرفه؛ زر «إضافة» ← `addAttachment`
