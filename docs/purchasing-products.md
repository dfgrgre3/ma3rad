# توثيق صفحات المشتريات والمنتجات والتسعير

> توثيق عناصر التحكم التفاعلية في صفحات المشتريات (طلبات، عروض أسعار، أوامر شراء، استلام، وارد، مرتجعات، مطالبات، كشف حساب موردين) وصفحات المنتجات والتسعير. الصلاحيات (Permissions) تُذكر مع العناصر عند الحاجة.

## `/purchases/requests` — طلبات الشراء والتوريد الداخلي
- **الملف:** `src/pages/purchasing/purchase-requests/PurchaseRequestsPage.tsx`
- **الوصف:** إدارة طلبات الشراء والتوريد الداخلي مع اقتراحات حد إعادة الطلب والاعتماد المتدرج حسب القيمة المالية (مستوى 1 تحت 25,000 ج.م، مستوى 2 للأعلى).
- **العناصر التفاعلية:**
  - زر «اقتراحات حد إعادة الطلب» (أصفر، يحتاج `ui.purchases.requests.create`) ← يفتح مودال «اقتراحات الشراء الآلية من حد إعادة الطلب» عبر `ProcurementService.getReorderSuggestions()`
    - في المودال: زر «استيراد وتحويل لطلب شراء» ← يملأ مودال طلب جديد بالاقتراحات ويفتحه تلقائياً
  - زر «طلب توريد جديد» (برتقالي، يحتاج create) ← يفتح مودال «تقديم طلب توريد جديد» (يحمّل المنتجات والمخازن)
    - في المودال: إضافة/حذف صنف (ProductPicker لكل سطر + حذف Trash2 + زر «إضافة صنف»)، «إلغاء»، «تقديم الطلب» ← يستدعي `PurchaseRequestService.createRequest()`
  - بحث برقم الطلب/مقدم الطلب + قائمة «كل الحالات» للتصفية
  - في كل صف جدول:
    - زر «البنود» ← يوسّع الصف ويعرض بنود الطلب (`getItemsAsync`)
    - (PENDING) أيقونة اعتماد ✓ ← `service.decide(id,'APPROVED')` مع تأكيد (يحدد مستوى الاعتماد حسب القيمة)
    - (PENDING) أيقونة رفض ✗ ← `decide(...,'REJECTED')`
    - (PENDING) أيقونة إلغاء ✕ ← `decide(...,'CANCELLED')`
    - (APPROVED) زر «RFQ» ← ينقل إلى `/purchases/quotations`
    - (APPROVED) زر «أمر شراء» (يحتاج approve) ← `decide(...,'ORDERED')` — يحوّل الطلب لأمر شراء

## `/purchases/quotations` — طلبات عروض الأسعار والمقارنة (RFQ)
- **الملف:** `src/pages/purchasing/supplier-quotations/SupplierQuotationsPage.tsx`
- **الوصف:** إنشاء طلبات عروض أسعار (RFQ)، تسجيل عروض الموردين التنافسية، ومصفوفة مقارنة مع ترسية العرض وإنشاء أمر شراء آلياً.
- **العناصر التفاعبية:**
  - زر «طلب عروض أسعار جديد (RFQ)» (برتقالي، يحتاج `ui.purchases.quotations.create`) ← يفتح مودال إنشاء RFQ
    - في المودال: «+ إضافة صنف آخر» يضيف سطراً (ProductPicker + كمية + حذف ✕)، «إلغاء»، «حفظ وطرح طلب العروض» ← `service.createRfq()` ثم يعرض تفاصيل الطلب
  - بحث + فلتر حالة RFQ + زر «تحديث»
  - قائمة RFQs (عمود يسار): النقر على بطاقة طلب ← يعرض تفاصيله و عروضه في اللوحة اليمنى (`getRfqByIdAsync`)
  - في تفاصيل RFQ: زر «تسجيل عرض سعر مورد جديد» (أخضر، يظهر إن لم تكن AWARDED/CANCELLED) ← يفتح مودال «تسجيل عرض سعر مورد لـ {رقم الطلب}»
    - في المودال: اختيار المورد، رقم العرض، مدة التوريد، شروط الدفع، الجودة، صلاحية العرض، أسعار الأصناف، «إلغاء»، «حفظ وإدراج العرض للمقارنة» ← `service.addSupplierQuotation()`
  - في بطاقة كل عرض مورد: زر «ترسية العرض وإنشاء أمر شراء» (يحتاج `ui.purchases.quotations.approve`) ← تأكيد ثم `service.awardQuotation()` يُنشئ أمر شراء آلياً

## `/purchases/orders` — أوامر الشراء
- **الملف:** `src/pages/purchasing/purchase-orders/PurchaseOrdersPage.tsx`
- **الوصف:** أوامر الشراء للموردين من المسودة حتى الاستلام مع ترحيل فاتورة توريد تلقائياً عند الاستلام، وحقول تشغيلية مخصصة.
- **العناصر التفاعبية:**
  - زر تحديث (أيقونة RefreshCw) + زر «أمر شراء جديد» (برتقالي، يحتاج create) ← يفتح مودال «أمر شراء جديد» (مورد + مخزن + تاريخ توريد + بنود + `OperationalFieldsForm` «بيانات إضافية لأمر الشراء»)
    - في المودال: ProductPicker لكل بند، حذف بند (Trash2)، «إضافة صنف»، «إلغاء»، «حفظ الأمر» ← `PurchaseOrderService.createOrder()` كمسودة
  - بحث برقم الأمر/المورد + فلتر الحالة + `OperationalFieldsFilter` للحقول المخصصة
  - في كل صف: زر تفاصيل (Eye) ← يوسّع عرض البنود + ملخص/محرر الحقول التشغيلية (`OperationalFieldsRecordEditor`)
    - (DRAFT) أيقونة «إرسال للمورد» ← `changeStatus → SENT`
    - (SENT) أيقونة «تأكيد» ← `→ CONFIRMED`
    - (غير RECEIVED/CANCELLED) أيقونة «استلام وترحيل فاتورة» (Truck) ← `receiveOrder()` مع تأكيد — ينشئ فاتورة توريد
    - (غير RECEIVED/CANCELLED) أيقونة «إلغاء» (Ban) ← تأكيد ثم `→ CANCELLED`

## `/purchases/receipts` — إذونات الاستلام المخزني (GRN)
- **الملف:** `src/pages/purchasing/goods-receipts/GoodsReceiptsPage.tsx`
- **الوصف:** أذونات الاستلام المخزني وفحص الجودة والدفعات (رقم لوت، شيد، كاليبر، فرز) مع حصر المقبول/التالف/العجز.
- **العناصر التفاعبية:**
  - زر «إذن استلام مخزني جديد» (كهرماني، يحتاج `ui.purchases.receipts.create`) ← يفتح مودال GRN (تحميل الموردين/المنتجات/المخازن/أوامر الشراء المفتوحة)
    - في المودال: اختيار «ربط بأمر شراء مفتوح» ← `handleSelectPo` يملأ البنود تلقائياً من الأمر (قراءة فقط)
    - اختيار المورد (يتعطل عند ربط أمر شراء) والمخزن المستلم، رقم إذن التسليم، رقم السيارة، اسم السائق
    - «+ إضافة صنف» (يظهر فقط بدون ربط بأمر شراء) ← يضيف بند فحص
    - لكل بند: ProductPicker، كميات المستلم/التالف/العجز (السليم يُحسب تلقائياً)، رقم التشغيلة، الشيد، الكاليبر، الفرز، ملاحظات الفحص
    - «إلغاء» و«اعتماد الاستلام وتحديث المخزون» ← `service.createGoodsReceipt()`؛ عند وجود تالف/عجز يظهر تأكيد «فتح شاشة تسجيل مطالبة مورد فوراً؟» ← ينقل إلى `/purchases/claims`
  - بحث + فلتر حالة الفحص + زر «تحديث»
  - لكل إذن: سهم التوسيع (ChevronDown) ← يعرض جدول تفاصيل الفحص
    - إن وُجد تالف/عجز: زر «فتح صفحة المطالبات» ← `/purchases/claims`

## `/purchases/incoming` — البضائع المنتظرة
- **الملف:** `src/pages/purchasing/incoming-products/IncomingProductsPage.tsx`
- **الوصف:** متابعة أوامر الشراء المفتوحة (مرسل/مؤكد/استلام جزئي) والكميات التي لم تصل بعد مع موعد الوصول المتوقع وسجل الاستلام.
- **العناصر التفاعبية:**
  - بحث + checkbox «المتأخرة فقط» + فلاتر المورد/المخزن/الحالة/نطاق تاريخ الوصول + زر «تحديث»
  - زر «جدول بيانات» ← تصدير Excel (`exportToExcel`) و«طباعة / مستند» ← PDF
  - النقر على رأس كل طلب ← يوسّع «سجل الاستلام» (الفواتير والاستلامات السابقة)
  - زر «تسجيل استلام» (أخضر، في كل طلب) ← يفتح مودال «استلام من أمر {رقم}» لإدخال الكميات المستلمة لكل صنف + ملاحظات
    - «إلغاء» / «تأكيد الاستلام» ← `service.receiveQuantities()` ينشئ فاتورة ويحدّث المخزون
  - (بصلاحية `ui.purchases.incoming.update`) حقول «موعد الوصول المتوقع» و«ملاحظات المتابعة» ← تُحفظ عند blur عبر `service.updateFollowUp()`

## `/purchases/returns` — مرتجعات الشراء
- **الملف:** `src/pages/purchasing/purchase-returns/PurchaseReturnsPage.tsx`
- **الوصف:** تسجيل مرتجعات الشراء للموردين مع عكس المخزون وتسوية القيمة (خصم من حساب المورد أو استرداد نقدي).
- **العناصر التفاعبية:**
  - زر «جدول بيانات» و«مستند» ← معاينة التصدير عبر `DocumentPreviewModal` (مع خيار تحميل Excel)
  - زر تحديث (RefreshCw) + زر «تسجيل مرتجع» (أحمر، يحتاج `ui.purchases.returns.return`) ← يفتح مودال «تسجيل مرتجع شراء» (اختيار فاتورة شراء ← تحميل الأصناف القابلة للإرجاع، إدخال كميات، طريقة التسوية «خصم من حساب المورد»/«استرداد نقدي»، سبب الإرجاع، حقول تشغيلية)
    - «إلغاء» / «ترحيل المرتجع» ← `PurchaseReturnService.createReturn()` (idempotency) — يحدّث المخزون وحساب المورد
  - بحث + فلاتر الحقول التشغيلية + نطاق تاريخ + زر «تفريغ» لمسح الفلاتر
  - في كل صف: زر «تفاصيل» (Eye) ← يفتح مودال تفاصيل المرتجع (أصناف، تسوية، حقول تشغيلية قابلة للتحرير `OperationalFieldsRecordEditor`، وزر «طباعة المرتجع» ← `PrintService.printPurchaseReturn()`)
  - زر طباعة (Printer) في كل صف ← طباعة المرتجع مباشرة
  - ترقيم الصفحات (السابق/التالي) عند تجاوز 15 عنصراً

  - زر «إعادة المحاولة» عند فشل التحميل

## `/suppliers/:id` — ملف المورد التفصيلي
- **الملف:** `src/pages/purchasing/supplier-detail/SupplierDetailPage.tsx` (+ مكوّنات `SupplierHeader`, `OverviewTab`, `InvoicesTab`, `PaymentsTab`, `OrdersTab`, `ReturnsTab`, `StatementTab`, `ScorecardTab`, `PriceHistoryTab`, `RecordPaymentModal`, `EditSupplierModal`)
- **الوصف:** صفحة ملف المورد الكاملة بثمانية تبويبات: نظرة عامة، فواتير، سندات صرف، أوامر شراء، مرتجعات، كشف حساب، تقييم أداء، وسجل أسعار.
- **العناصر التفاعبية:**
  - زر الرجوع (سهم) ← ينقل إلى `/suppliers`
  - زر «سند صرف دفعة» (أخضر، `ui.suppliers.supplier_detail.payment`) ← يفتح مودال «سند صرف / سداد دفعة للمورد» (مبلغ، طريقة الدفع: نقدي/تحويل بنكي/شيك، بيان) ← «تأكيد وسداد» يستدعي `supplierService.recordPayment()`
  - زر «تعديل البيانات» (Pencil) ← يفتح مودال «تعديل بيانات المورد» (كل الحقول + حقول تشغيلية) ← «حفظ التعديلات» يستدعي `updateSupplier()`
  - زر «إعادة التفعيل» / «تعطيل الحساب» (يحتاج delete+update) ← تأكيد ثم يبدّل `isActive`
  - زر «طباعة كشف الحساب» ← ينتقل لتبويب كشف الحساب ثم `window.print()`
  - الهاتف والبريد في الهيدر روابط `tel:` و`mailto:`
  - التبويبات (مع عدّادات): «نظرة عامة»، «فواتير الشراء والتوريد»، «سندات الصرف والمدفوعات»، «أوامر الشراء»، «مرتجعات الشراء»، «كشف الحساب التفصيلي»، «سجل أداء المورد»، «سجل أسعار الشراء» (بعضها يتطلب صلاحيات purchases/finance)
  - **نظرة عامة:** زر «تعديل» في بطاقة بيانات الاتصال ← مودال التعديل؛ «عرض الكل (n)» بجانب «آخر فواتير التوريد» ← تبويب الفواتير؛ «عرض الكل (n)» بجانب «آخر سندات الصرف» ← تبويب المدفوعات
  - **فواتير:** زر «فاتورة شراء جديدة» (رابط) ← `/purchases`
  - **سندات الصرف:** زر «تسجيل سند صرف جديد» ← مودال السداد
  - **أوامر الشراء:** زر «إنشاء أمر شراء جديد» (رابط) ← `/purchases/orders`
  - **مرتجعات الشراء:** زر «تسجيل مرتجع شراء» (رابط) ← `/purchases/returns`
  - **كشف الحساب:** تاريخا «من/إلى» يعيدان تحميل الكشف، «إلغاء التصفية»، «تصدير CSV»، «طباعة كشف الحساب» (`window.print()`)
  - **سجل أداء المورد / سجل أسعار الشراء:** جداول قراءة فقط (لا أزرار)
  - عند عدم وجود المورد: زر «العودة لقائمة الموردين» ← `/suppliers`

    - «طريقة توزيع التكلفة» (حسب القيمة/المساحة/الوزن) + حقول التكلفة الإضافية: النقل، العتالة، جمارك، تأمين، أخرى
    - الخصم، المبلغ المسدد نقداً، طريقة السداد (آجل/نقدي/تحويل بنكي)، حقول تشغيلية «بيانات إضافية لفاتورة الشراء»
    - «إلغاء» / «حفظ الفاتورة وتثبيت تكاليف الوصول» ← `purchaseService.createPurchase()` (مع فحص تكرار رقم فاتورة المورد)
  - بحث برقم الفاتورة/المورد + فلاتر الحقول التشغيلية
  - زر التوسيع (ChevronDown) في كل صف ← يعرض بنود الفاتورة مع نصيب كل صنف من تكاليف الوصول وتكلفة الوصول الفعلية + ملخص/محرر الحقول التشغيلية

## `/products/:id` — تفاصيل المنتج
- **الملف:** `src/pages/products/product-detail/ProductDetailPage.tsx` (+ `ProductDetailHeader`, `ProductEditModal`, ومكوّنات التبويبات)
- **الوصف:** ملف المنتج الكامل: نظرة عامة، الدفعات والنغمات، المخزون، المبيعات، المشتريات، الأسعار، المتغيرات، الصور، المستندات، السجل، النشاط.
- **العناصر التفاعبية:**
  - زر الرجوع (سهم) ← `/products`
  - زر «تعديل» (أزرق، يحتاج `ui.products.detail.update`) ← يفتح مودال «تعديل الصنف» (`ProductEditModal`) بحقول البيانات والأسعار والمخزون ← «حفظ» يستدعي `productService.updateProduct()`
  - التبويبات (تُفلتر بالصلاحيات): «نظرة عامة»، «الدفعات والنغمات»، «المخزون»، «المبيعات»، «المشتريات»، «الأسعار»، «الأنواع والمتغيرات»، «الصور»، «المستندات»، «السجل»، «النشاط»
  - **الدفعات والنغمات (BatchesTab):** زر «تسجيل استلام دفعة / تشغيلة» (يحتاج `inventory.adjust`) ← نموذج استلام دفعة (مخزن، نغمة/شيد، كاليبر، كمية...) ← حفظ؛ زر حذف دفعة لكل صف (معطّل إن كان بها رصيد)
  - **الأنواع والمتغيرات (VariantsTab):** نموذج إضافة متغير (اسم، باركود، لون، مقاس، فرز، تكلفة/سعر إن سمحت الصلاحيات) ← زر «إضافة»؛ زر حذف (Trash2) لكل متغير
  - **الصور (ImagesTab):** نموذج رفع صورة ← «إضافة»؛ زر «تعيين كرئيسية»؛ زر حذف صورة
  - **المستندات (DocumentsTab):** نموذج إضافة مستند ← «إضافة»؛ زر حذف/أرشفة مستند
  - **الأسعار:** عرض `PriceListsForProduct` (قوائم أسعار المنتج) — قراءة فقط
  - **السجل:** `InventoryHistory` (حركات المخزون) — قراءة فقط
  - بقية التبويبات جداول قراءة فقط
  - عند عدم وجود المنتج: زر «العودة للمنتجات» ← `/products`

  - قسم قابل للطي «حقول إضافية للسجلات التشغيلية» ← يعرض `OperationalFieldsManager` (إضافة/تعديل/حذف حقول تشغيلية وخيارات فرز المنتجات — أزرار «حقل جديد»، «تعديل»، «حذف»، «إضافة خيار»، «حفظ الحقل»)
