# توثيق صفحات المخزون (Inventory)

توثيق تفاعلي لصفحات قسم المخزون في تطبيق ERP (`src/pages/inventory/`). كل قسم يذكر الملف، الوصف، وكل زر/تبويب/عنصر تحكم تفاعلي مع ما يفعله.

---

## `/inventory` و `/inventory/hub` — مركز المخزون (InventoryHubPage)

- **الملف:** `src/pages/inventory/inventory-hub/InventoryHubPage.tsx`
- **الوصف:** صفحة Hub مركزية تجمّع كل شاشات المخزون داخل `WorkspaceHub` مع تابات تنقّل مرتبطة بالمسارات الفرعية (`/inventory/*`). الصفحة الرئيسية `/inventory` تعرض تبويب «نظرة عامة» الذي يحمّل `components/inventory/InventoryView` (خارج نطاق هذه الصفحات). التبويبات تُرشَّح تلقائياً حسب صلاحيات المستخدم (`useRouteAccess`).
- **العناصر التفاعلية:**
  - تبويب «نظرة عامة» ← يفعّل `/inventory` ويعرض `InventoryView`.
  - تبويب «أرصدة المخازن» ← `/inventory/warehouse-stock` ويعرض `LocationStockPage` بوضع `mode="warehouse"`.
  - تبويب «أرصدة المعارض» ← `/inventory/showroom-stock` ويعرض `LocationStockPage` بوضع `mode="showroom"`.
  - تبويب «تنبيهات المخزون» ← `/inventory/alerts` ويعرض `InventoryAlertsPage`.
  - تبويب «سجل الحركة» ← `/inventory/ledger` ويعرض `StockLedgerPage`.
  - تبويب «التحويلات» ← `/inventory/transfers` ويعرض `StockTransfersView`.
  - تبويب «الجرد» ← `/inventory/counts` ويعرض `InventoryCountPage`.
  - تبويب «التقييم» ← `/inventory/valuation` ويعرض `InventoryValuationPage`.
  - تبويب «التسويات» ← `/inventory/adjustments` ويعرض `InventoryAdjustmentsPage`.
  - تبويب «حجوزات المخزون» ← `/inventory/stock-reservations` ويعرض `StockReservationsPage`.
  - تبويب «إعادة الطلب» ← `/inventory/reorder-planning` ويعرض `ReorderPlanningPage`.
  - تبويب «مواقع الرفوف» ← `/inventory/locations` ويعرض `WarehouseLocationsPage`.
  - تبويب «التالف والحجر» ← `/inventory/damage-quarantine` ويعرض `DamageQuarantinePage`.
  - تبويب «المطابقة» ← `/inventory/reconciliation` ويعرض `InventoryReconciliationPage`.
  - ملاحظة: تبويب «الصلاحية» (`ExpiryPage`) غير موجود في هذه القائمة؛ الصفحات تُحمَّل lazy حسب المسار الفعلي.

## `/inventory/showroom-stock` — أرصدة المعارض (`mode="showroom"`)

- **الملف:** `src/pages/inventory/location-stock/LocationStockPage.tsx`
- **الوصف:** صفحة موحدة تخدم وضعين. في وضع المخزن: جدول بكل الأصناف ذات الرصيد في المخازن (المخزن، الصنف، المقاس، الرصيد بوحدة الصنف، الرصيد بالكرتونة). في وضع المعرض: مقارنة أرصدة كل الأصناف بين مخزن معرض ومخزن عادي، مع حالة «غير مسجل» و«غير متوفر». تتطلب صلاحية `inventory.warehouse_stock.view` أو `inventory.showroom_stock.view`.
- **العناصر التفاعلية:**
  - زر «تحديث البيانات» (أيقونة RefreshCw) ← يعيد تحميل المخازن والأصناف وأرصدة المخزون (`loadData`).
  - حقل بحث «بحث باسم الصنف أو الكود أو المقاس...» ← يفلتر الأصناف حسب الاسم/SKU/الباركود/المقاس.
  - (وضع المخزن) قائمة «المخزن» ← «كل المخازن» أو مخزن محدد لتصفية الجدول.
  - (وضع المعرض) قائمة «مخزن المعرض» ← اختيار مخزن من نوع SHOWROOM؛ لا يمكن اختيار نفس المخزن للجهتين.
  - (وضع المعرض) قائمة «المخزن» ← اختيار المخزن المقارن (غير SHOWROOM).
  - (وضع المعرض) قائمة «فلترة الأصناف» ← «كل الأصناف / موجود في المعرض فقط / موجود في المخزن فقط / موجود في الاثنين / غير متوفر في الاثنين».

## `/inventory/ledger` — سجل حركة المخزون

- **الملف:** `src/pages/inventory/stock-ledger/StockLedgerPage.tsx`
- **الوصف:** دفتر حركة المخزون الكامل من جدول `inventory_transactions` مع الرصيد السابق والرصيد بعد الحركة محسوبين بنافذة SQL، ورقم مرجع مستخرج من الفواتير/المرتجعات/التحويلات/الجرد/التسويات. يُقيَّد النطاق حسب فروع المستخدم (`warehouseBranchScope`).
- **العناصر التفاعلية:**
  - زر «تصدير» (Download) ← يصدّر سجل الحركة المفلتر إلى Excel عبر `exportToExcel` (يتطلب صلاحية `inventory.export`).
  - حقل بحث «بحث بالمنتج أو رقم المرجع...» ← يبحث في اسم المنتج، رقم الحركة، المرجع، وأرقام الفواتير/التحويلات/الجرد/التسويات.
  - قائمة «كل الأنواع» ← فلترة حسب نوع الحركة (شراء، بيع، مرتجع شراء/بيع، تحويل وارد/صادر، تسوية، رصيد افتتاحي، جرد، تالف، إلغاء...).
  - قائمة «كل المخازن» ← فلترة حسب المخزن.
  - حقول تاريخ «من» و«إلى» ← فلترة بمدى تاريخي.
  - زرا الترقيم «السابق» / «التالي» ← تنقّل بين صفحات النتائج (50 حركة لكل صفحة).

## `/inventory/transfers` — التحويلات المخزنية (StockTransfersView)

- **الملف:** `src/pages/inventory/stock-transfers/StockTransfersPage.tsx` (+ مكونات `components/` + hooks في `src/hooks/pages/inventory/stock-transfers/`)
- **الوصف:** إدارة دورة حياة التحويل المخزني كاملة: طلب ← اعتماد ← تجهيز ← إرسال ← استلام جزئي/كامل مع توثيق الفقد/الكسر. يتضمن 3 تبويبات: أوامر التحويل النشطة، سجل الحركات المنفذة، وملخص حركة المخازن.
- **العناصر التفاعلية:**
  - زر «طلب تحويل مخزني جديد» (Plus) ← يفتح `CreateTransferModal` (يتطلب `inventory.transfer`).
  - زر «تحديث» (RefreshCw) ← يعيد تحميل بيانات التحويلات والمخازن والأصناف والملخص.
  - تبويب «أوامر التحويل النشطة (n)» ← يعرض `WorkflowTransfersTable`.
  - تبويب «سجل حركات التحويل المنفذة (n)» ← يعرض `TransferHistoryTable` (حركات مفلترة).
  - تبويب «ملخص حركة المخازن» ← يعرض `WarehouseSummaryGrid` (إجمالي الوارد/الصادر لكل مخزن؛ يتطلب `inventory.view`).
  - قائمة «جميع الحالات» (في تبويب الأوامر النشطة) ← فلترة: طلبات جديدة، معتمدة، قيد التجهيز، قيد النقل، مستلمة بالكامل، استلام جزئي، مكتملة مع فقد موثق، مرفوضة.
  - زر «التفاصيل» (في كل صف) ← يفتح `TransferDetailsModal` مع بنود التحويل والمطلوب/المشحون/المستلم/الفقد.
  - زر «اعتماد» (حالة REQUESTED) ← يستدعي `approveTransfer` بعد تأكيد.
  - زر «رفض» (REQUESTED أو IN_TRANSIT) ← يطلب سبب الرفض عبر `prompt` ثم يستدعي `rejectTransfer`.
  - زر «بدء التجهيز» (APPROVED) ← `prepareTransfer` (يتطلب `inventory.transfer.execute`).
  - زر «إرسال وشحن» (PREPARING) ← تأكيد ثم `dispatchTransfer`.
  - زر «استلام البضاعة» (IN_TRANSIT) ← يفتح `ReceiveTransferModal` (يتطلب `inventory.transfer.receive`).
  - (مودال إنشاء التحويل) زر «إضافة صنف» ← يضيف سطر صنف؛ زر × بجانب كل سطر ← يحذفه؛ زر «إلغاء»؛ زر «إرسال الطلب للاعتماد» ← `createTransferRequest` مع التحقق من عدم تطابق المخزنين.
  - (مودال الاستلام) حقول «المستلم صالح / فقد وعجز / كسر وتالف» لكل صنف؛ زر «تأكيد الاستلام وإضافة الرصيد» ← `receiveTransfer` بمفتاح idempotency؛ زر «إلغاء».
  - (مودال التفاصيل) زر «إغلاق».

## `/inventory/counts` — جرد المخزون

- **الملف:** `src/pages/inventory/inventory-count/InventoryCountPage.tsx` (+ `InventoryCountHeader.tsx`, `CountSessionsToolbar.tsx`, `CountSessionsTable.tsx`, `StartCountSessionModal.tsx`, `SessionCountModal.tsx`)
- **الوصف:** جلسات جرد دورية/مفاجئة/أعمى. دورة: بدء جلسة (تجميد أرصدة النظام) ← إدخال العد الفعلي ← حفظ مسودة أو ترحيل الفروقات ← مراجعة واعتماد من مستخدم آخر (REVIEW). يتطلب `inventory.count` للبدء و`ui.inventory.counts.approve` للاعتماد.
- **العناصر التفاعلية:**
  - زر «بدء جلسة جرد جديدة» ← يفتح `StartCountSessionModal` ويحمّل منتجات المخزن المختار.
  - حقل بحث «بحث برقم الجلسة، المخزن، أو القائم بالجرد...» وفلتر حالة الجلسة (كل الحالات/قيد الجرد/بانتظار المراجعة/مرحل/ملغى).
  - زر «إدخال الجرد» أو «عرض التقرير» (لكل جلسة في الجدول) ← يفتح `SessionCountModal`.
  - (مودال بدء الجلسة) اختيار «المخزن المراد جرده» (يُعيد تحميل المنتجات)؛ نوع الجرد: جرد كلي شامل / دوري مجدول / مفاجئ / عدّ أعمى / جزئي / عشوائي سريع؛ checkbox «تفعيل العد الأعمى (Blind Count)»؛ بحث الأصناف + checkboxes لاختيار أصناف الجرد الجزئي؛ زر «توليد جلسة وبدء الجرد» ← `startCountSession`؛ زر «إلغاء».
  - (مودال جلسة الجرد) حقول إدخال «الجرد الفعلي» لكل صنف، قائمة «سبب الفارق» (كسر وتلف/عجز/خطأ عد/خطأ إدخال/عجز توريد/أخرى)، حقول ملاحظات؛ بحث «بحث داخل أصناف الجرد...».
  - زر «حفظ كمسودة» ← `saveCountDraft`.
  - زر «إلغاء الجلسة» ← `confirm` ثم `cancelCountSession` (دون تعديل الأرصدة).
  - زر «اعتماد وترحيل فروقات الجرد» (حالة COUNTING) ← `submitCountSession`.
  - زر «رفض وإعادة للعد» (حالة REVIEW + صلاحية) ← `prompt` للسبب ثم `rejectCountSession`.
  - زر «اعتماد وترحيل الفروقات» (حالة REVIEW + صلاحية) ← `approveCountSession`.
  - زر «Excel» و«PDF / Print» (لجلسة مرحّلة فقط) ← تصدير تقرير الجرد عبر `exportToExcel`/`exportToPdf` بصلاحية `inventory.export`.
  - زر «إغلاق» و«X» ← إغلاق المودال.

## `/inventory/adjustments` — تسويات المخزون

- **الملف:** `src/pages/inventory/inventory-adjustments/InventoryAdjustmentsPage.tsx` + `InventoryAdjustmentModals.tsx`
- **الوصف:** طلبات التسوية المخزنية بدورة اعتماد: إنشاء ← اعتماد من مستخدم آخر ← ترحيل مخزني/مالي. الأنواع: إضافة رصيد (+)، عجز/سحب (-)، تالف (-). شريط علوي يعرض عدد الطلبات المعلقة وإرشادات الصلاحيات المطلوبة.
- **العناصر التفاعلية:**
  - زر «طلب تسوية جديد» (Plus) ← يفتح مودال إنشاء التسوية (يتطلب `inventory.adjust`).
  - حقل بحث «بحث برقم التسوية، المخزن، أو السبب...».
  - زر «عرض البنود» (FileText، في كل صف) ← يفتح مودال «تفاصيل تسوية المخزون» مع بنود الأصناف والتكلفة والقيمة.
  - زر «اعتماد» (CheckCircle2، للطلب المعلق غير المعتمد ومنشئ مختلف) ← `approveAdjustment` (يتطلب `inventory.adjustment.approve`).
  - زر «ترحيل» (CheckCircle2، للطلب المعتمد المعلق) ← `postAdjustment` (يتطلب `inventory.adjustment.post`).
  - (مودال التفاصيل) زر «إغلاق التفاصيل» و«X» ← إغلاق.
  - (مودال الإنشاء) أزرار نوع التسوية: «إضافة رصيد (+)» / «عجز / سحب (-)» / «تالف (-)»؛ اختيار مخزن؛ `ProductPicker` لاختيار الصنف؛ حقول الكمية والسبب والملاحظات؛ زر «إلغاء»؛ زر «حفظ التسوية» ← `createAdjustment`.
  - ملاحظة: الصفحة تدعم فتح مودال التفاصيل مباشرة عبر query param `?adjustmentId=...`.

## `/inventory/stock-reservations` — حجوزات المخزون

- **الملف:** `src/pages/inventory/stock-reservations/StockReservationsPage.tsx` (غلاف رفيع يعيد تصدير `ReservationsDepositPage` بوضع `mode="inventory"` من `src/pages/sales/reservations/`)
- **الوصف:** واجهة المخزون لحجوزات الأصناف وتجميد الكميات — تُحمّل بيانات الحجوزات فقط (بدون طلبات/عملاء المبيعات). تبويب «سجل حجز الأصناف بالمخازن» فقط في هذا الوضع. يتطلب `inventory.reservations.view` أو `inventory.view`؛ الإجراءات تتطلب `inventory.adjust`.
- **العناصر التفاعلية:**
  - زر «تحديث الصلاحيات» (Clock) ← يستدعي `resService.expireOverdue()` لفك الحجوزات المنتهية وتحديثها (يتطلب `inventory.adjust`).
  - زر «حجز كمية بضاعة يدوياً» (Plus) ← يفتح `NewReservationModal`.
  - تبويب «سجل حجز الأصناف بالمخازن (n)» ← يعرض `StockReservationsTable`.
  - حقل بحث وفلتر حالة الحجز (نشط/مُفرج/مُنفّذ/منتهي) وزر «تحديث البيانات» (RefreshCw) في شريط الأدوات.
  - زر «صرف» (في كل حجز نشط) ← `confirm` ثم `consumeReservation` لخصم الكمية من المخزون فعلياً.
  - زر «إلغاء الحجز» (في كل حجز نشط) ← `confirm` ثم `releaseReservation` لإرجاع الكمية للمخزون الحر.
  - (مودال حجز جديد) اختيار الصنف عبر `ProductPicker` واختيار المخزن ← يعرض فوراً بطاقة «الرصيد الفعلي / المحجوز حالياً / المتاح للحجز»؛ حقول الكمية وتاريخ الانتهاء ونوع المرجع (يدوي/طلب/عرض سعر/مشروع) ورقم المرجع والملاحظات؛ زر «إلغاء»؛ زر «تأكيد حجز الكمية» ← `createReservation` مع التحقق من توفر الكمية.

## `/inventory/reorder-planning` — التخطيط وإعادة الطلب

- **الملف:** `src/pages/inventory/reorder-planning/ReorderPlanningPage.tsx`
- **الوصف:** لوحة مراقبة حدود الأمان ومعدل المبيعات اليومي مع اقتراح كميات الشراء و«أيام النفاذ».KPIs: نفد المخزون، تحت حد الأمان، بلغت نقطة الطلب، قيمة التوريد المقترحة. يمكن إنشاء طلب شراء آلي عبر `PurchaseRequestService` وتعديل محددات التخطيط لكل صنف.
- **العناصر التفاعلية:**
  - زر «إنشاء طلب شراء للمحدد (n)» (ShoppingCart) ← ينشئ طلب شراء HIGH الأولوية للأصناف المحددة في المخزن المختار عبر `PurchaseRequestService.createRequest` (يظهر عند تحديد أصناف وبصلاحية `purchases.create` أو `inventory.reorder.manage`).
  - زر «تحديد الأصناف الحرجة» / «اختر مستودعاً أولاً» ← يحدد كل الأصناف OUT_OF_STOCK/CRITICAL/REORDER_NEEDED.
  - زر «تحديث» (RefreshCw) ← يعيد تحميل البيانات.
  - حقل بحث «بحث بالاسم، الكود، الباركود...» (Enter يعيد التحميل) وقائمة «جميع المخازن».
  - أزرار فلترة الحالة: «الكل» / «نفد» / «حرج» / «إعادة طلب» مع العدّادات.
  - checkbox رأس الجدول «تحديد الكل» وcheckbox كل صف ← تحديد أصناف لطلب الشراء (يتطلب اختيار مستودع واحد).
  - زر أيقونة SlidersHorizontal «تعديل الحدود ونقاط الطلب» (لكل صف، بصلاحية `inventory.reorder.manage`) ← يفتح مودال «تعديل محددات الطلب والأمان».
  - (مودال التعديل) حقول: نقطة إعادة الطلب، كمية الأمان الاحتياطية، مهلة التوريد (Lead Time)، الحد الأدنى/الأقصى؛ زر «إلغاء»؛ زر «حفظ التعديلات» ← `updateProductPlanningParameters`.

## `/inventory/locations` — مواقع الرفوف والباركود

- **الملف:** `src/pages/inventory/warehouse-locations/WarehouseLocationsPage.tsx`
- **الوصف:** إدارة مواقع التخزين الهرمية (منطقة/ممر/رف/خانة) مع باركود داخلي وشريط إشغال السعة، وعرض/تسكين أصناف الرفوط، وطباعة ملصقات باركود. الصلاحيات عبر `inventory.locations.manage`.
- **العناصر التفاعلية:**
  - زر «إضافة موقع تخزين» (Plus) ← يفتح مودال إضافة/تعديل الموقع.
  - زر «تحديث» (RefreshCw)؛ حقل بحث «بحث بالباركود، الممر، الرف...» (Enter يعيد التحميل)؛ قائمة «جميع المخازن».
  - أيقونة Printer «طباعة ملصق الباركود» (على كل بطاقة موقع) ← يفتح مودال معاينة الملصق.
  - زر «عرض البضائع (n)» (Eye) ← يفتح مودال «البضائع المخزنة في الموقع» مع أصناف الموقع.
  - أيقونا Edit3 «تعديل الموقع» وTrash2 «حذف الموقع» (بصلاحية manage) ← تعديل أو حذف الموقع بعد `confirm`.
