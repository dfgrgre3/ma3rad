# صفحات لوحة تحكم المنصة (Platform Admin)

توثيق الصفحات الإدارية الخاصة بمالك المنصة (SaaS owner) في `src/pages/platform/`. تتضمن كل صفحة وصف وظيفتها وقائمة بالعناصر التفاعلية (أزرار، تبويبات، قوائم، إجراءات صفوف، ومحتوى المودالات).

---

## `/platform` — لوحة تحكم المنصة (نظرة عامة بسيطة)
- **الملف:** `src/pages/platform/PlatformDashboardPage.tsx`
- **الوصف:** لوحة مؤشرات رئيسية تعرض إجمالي العملاء والاشتراكات والتراخيص والإيرادات، مع تنبيهات أمان وتراخيص قريبة الانتهاء، وإحصائيات استخدام الوحدات، وأحدث العملاء والمدفوعات والعمليات.
- **العناصر التفاعلية:**
  - بطاقة «إجمالي العملاء» ← رابط إلى `/platform/tenants`
  - بطاقة «إجمالي الإيرادات المحصلة» ← رابط إلى `/platform/billing`
  - بطاقة «إجمالي المبيعات (الفواتير)» ← رابط إلى `/platform/billing`
  - بطاقة «مستحقات غير محصلة» ← رابط إلى `/platform/billing`
  - بطاقة «الأجهزة المتصلة» ← رابط إلى `/platform/licenses`
  - بطاقة «اشتراكات تنتهي قريباً» ← رابط إلى `/platform/licenses`
  - تنبيه أمني/ترخيص ← كل تنبيه فيه `link` يعمل كـ Link للصفحة المرتبطة
  - زر «إدارة» في لوحة «تراخيص تقترب من الانتهاء» ← `/platform/licenses`
  - زر «العملاء» في لوحة «اشتراكات تقترب من الانتهاء» ← `/platform/tenants`
  - زر «الإدارة» في لوحة «إصدارات البرنامج» ← `/platform/product`
  - زر «عرض الكل» في لوحة «أحدث العملاء» ← `/platform/tenants`
  - زر «الفواتير» في لوحة «أحدث المدفوعات» ← `/platform/billing`
  - زر «السجل الكامل» في لوحة «آخر العمليات على المنصة» ← `/platform/audit`
  - الإجراءات السريعة: «إضافة عميل جديد» ← `/platform/tenants`، «إصدار ترخيص» ← `/platform/licenses`، «إنشاء فاتورة» ← `/platform/billing`، «إدارة المنتج والمزايا» ← `/platform/product`

## `/platform/super-admin` — لوحة مالك المنصة المتقدمة (تحليلات)
- **الملف:** `src/pages/platform/PlatformSuperAdminDashboard.tsx` (يستخدم `dashboard/usePlatformDashboardData.ts` ومكونات `components/Charts.tsx`)
- **الوصف:** نسخة متقدمة من لوحة التحكم مع تحليل مفصل مقسّم على أقسام (الأداء التجاري، العملاء، الاشتراكات، التراخيص، التشغيل)، مخططات خطية ودائرية، مقارنة فترات زمنية، وتحديث تلقائي كل 60 ثانية.
- **العناصر التفاعلية:**
  - محدد الفترة `PeriodSelector` ← يغيّر الفترة الزمنية: «7 أيام / 30 يوم / 90 يوم / 180 يوم / 365 يوم / منذ أول السنة / الكل» ويعيد تحميل كل البيانات
  - قائمة «تصفية حسب الخطة» ← تصفية التحليلات حسب خطة (معطّلة في الوضع المركزي)
  - زر «تحديث» ← يعيد تحميل البيانات يدوياً
  - زر «إعادة المحاولة» (عند الخطأ) ← إعادة التحميل
  - بطاقة «إجمالي العملاء» ← `/platform/tenants`؛ بطاقة «إجمالي الإيرادات» ← `/platform/billing`؛ بطاقة «التراخيص السارية» ← `/platform/licenses`
  - الإجراءات السريعة (8 أزرار): «عميل جديد» ← `/platform/tenants?new=1` (يفتح معالج إنشاء عميل)، «إنشاء فاتورة» ← `/platform/billing`، «إدارة الاشتراكات» ← `/platform/subscriptions`، «الخطط والاشتراكات» ← `/platform/plans`، «الأجهزة والمزامنة» ← `/platform/devices`، «مراقبة المزامنة» ← `/platform/sync`، «سجل التدقيق» ← `/platform/audit`، «مركز الطوارئ» ← `/platform/emergency`
  - لوحة «حالة العملاء»: أزرار حالات «نشط / تجريبي / موقوف / منتهي / ملغي» ← تفتح `/platform/tenants?status=XXX`؛ زر «اشتراك ينتهي قريباً» ← `/platform/subscriptions`
  - لوحة «الأداء التجاري»: رابط «التحليلات» ← `/platform/analytics`؛ صفوف جداول العملاء ← `/platform/tenants`
  - لوحة «العملاء»: روابط «العملاء» ← `/platform/tenants` و«التحليلات» ← `/platform/analytics`؛ صفوف «أعلى العملاء إيراداً» و«عملاء ألغوا حديثاً» ← `/platform/tenants`
  - لوحة «أحدث العملاء المسجلين»: رابط «كل العملاء» ← `/platform/tenants`؛ كل صف عميل ← `/platform/tenants`
  - لوحة «الاشتراكات»: روابط «الاشتراكات» ← `/platform/subscriptions` و«التجديدات» ← `/platform/subscriptions?filter=renewals`؛ صفوف التجديدات والمتعثرة ← `/platform/tenants`
  - لوحة «التراخيص»: روابط «التراخيص» ← `/platform/licenses` و«الأجهزة» ← `/platform/devices`؛ صفوف التراخيص المعلقة ← `/platform/licenses`
  - لوحة «التشغيل»: روابط «الأجهزة» ← `/platform/devices`، «المزامنة» ← `/platform/sync`، «السجلات» ← `/platform/audit`
  - لوحة «تنتهي صلاحيتها قريباً»: روابط «الاشتراكات» ← `/platform/subscriptions`، «التراخيص» ← `/platform/licenses`؛ صفوف الاشتراكات/التراخيص ← الصفحات المعنية
  - لوحة «الإيراد حسب الخطة»: رابط «الخطط» ← `/platform/plans`
  - لوحة «نظرة على الباقات»: رابط «إدارة الباقات» ← `/platform/plans`؛ كل بطاقة باقة ← `/platform/plans`
  - لوحة «الوحدات والميزات»: رابط «إدارة الوحدات» ← `/platform/product`
  - لوحة «أحدث أحداث التدقيق»: رابط «سجل التدقيق» ← `/platform/audit`
  - لوحة «أحدث المدفوعات»: رابط «الفوترة» ← `/platform/billing`
  - لوحة «التنبيهات»: رابط «مركز الطوارئ» ← `/platform/emergency`؛ أزرار الإجراءات المقترحة داخل كل `AlertCard` ← تفتح `alert.link`
  - لوحة «التقارير والروابط السريعة»: روابط «التحليلات والتقارير» ← `/platform/analytics`، «العملاء» ← `/platform/tenants`، «الاشتراكات» ← `/platform/subscriptions`، «التراخيص» ← `/platform/licenses`، «الأجهزة والمزامنة» ← `/platform/devices`، «مركز الطوارئ» ← `/platform/emergency`، «سجل التدقيق» ← `/platform/audit`، «إعدادات المنصة» ← `/platform/settings`

## `/platform/user-platform-permissions` — منصة المستخدمين — الصفحات والصلاحيات
- **الملف:** `src/pages/platform/PlatformUserPlatformPermissionsPage.tsx`
- **الوصف:** عرض كامل لجميع صفحات المنصة وكل الصلاحيات على كل صفحة، مع التحكم الفعلي في ظهور القوائم وتعطيل الصلاحيات على مستوى العميل أو الخطة — تُحفظ على السيرفر المركزي (`tenant_feature_config`) عبر `centralPlatformClient`.
- **العناصر التفاعلية:**
  - حقل «مفتاح عميل/خطة» (نص) ← يحدد نطاق الإعدادات: `global` أو `tenantId` أو `plan:<planId>`
  - زر «إعادة التحميل» ← يعيد جلب إعدادات الصلاحيات من السيرفر المركزي
  - جدول «خريطة صلاحيات المسارات»: خانة اختيار «إظهار» لكل مسار ← تُظهر/تُخفي المسار (hiddenMenus)؛ أعمدة «المسار / all / any» للقراءة فقط
  - حقل «الصلاحيات المعطلة (كود صلاحية في كل سطر)» (textarea) ← قائمة disabledPermissions
  - حقل «featurePermissions (JSON)» (textarea) ← مدخلات JSON خام
  - زر «حفظ على السيرفر المركزي» ← يستدعي `centralPlatformClient.setFeaturePermissions` (PUT /api/v1/admin/config/feature-permissions)
  - جداول «صلاحيات المسار» أسفل الصفحة ← عرض فقط (الكود، الاسم، النوع، القسم)

  - زر «استيراد CSV» ← يفتح مودال الاستيراد
  - زر «عميل جديد» ← يفتح مودال إنشاء عميل (معالج 5 خطوات)

  - قسم «فلاتر متقدمة» (زر قابل للطي) ← نطاق تاريخ الإنشاء، نطاق المستحقات، استخدام الأجهزة، درجة الصحة، وزر «مسح الفلاتر»؛ عند وجود قوالب محفوظة: قائمة اختيار قالب + زر «+ حفظ» (يسأل عن اسم القالب ويحفظه في localStorage)

  - إجراءات كل صف في الجدول: زر «فتح الملف المركزي» (Eye) ← يفتح `TenantDetailModal`؛ زر «تعديل البيانات» (Pencil) ← يفتح `TenantFormModal` للتعديل؛ زر «الحساب والترخيص» (KeyRound) ← يفتح نفس الملف
  - **مودال «ملف العميل» (TenantDetailModal):**
    - في التذييل: «تصدير القائمة» ← CSV؛ «تعديل البيانات» ← مودال التعديل؛ «إرسال بيانات التفعيل» ← يجهز بيانات الدخول ويرسلها
    - أزرار الإجراءات: «إنشاء حساب للعميل» (إن لم يوجد حساب) ← يفتح `AccountModal`؛ «إعادة تعيين كلمة المرور»؛ «تعليق حساب الدخول / تفعيل حساب الدخول»؛ «إعادة تفعيل العميل» (إن كان SUSPENDED) أو «تعليق العميل»؛ «إعادة تعيين الأجهزة»؛ «إلغاء الاشتراك»؛ «الصفحات والمميزات» ← يفتح `TenantCatalogWizard`؛ «أرشفة العميل»
    - تبويبات الملف: «نظرة عامة»، «الاشتراك والباقة»، «التراخيص والتفعيلات»، «المدفوعات والفواتير»، «السجلات والنشاط»، «مستخدمو العميل»، «التحكم عن بعد»
    - **تبويب «نظرة عامة»:** زر «إضافة فرع» ← يفتح `BranchModal`؛ زر «إغلاق» لكل فرع غير رئيسي؛ نموذج Overrides: حقول النوع/الرمز/القيمة + زر «إضافة» ← `addOverride`؛ زر حذف (Trash) لكل override؛ زر «تجهيز بيانات التفعيل» و«نسخ اسم المستخدم» في بطاقة «حساب الدخول»؛ زر «إنشاء حساب» إن لم يوجد حساب
    - **تبويب «الاشتراك والباقة»:** زر «تجديد الاشتراك» (مع حقل مدة الأشهر) ← `renewSubscription`؛ زر «نقل العميل إلى الباقة الجديدة» (مع اختيار الباقة والمدة والمستخدمين) ← `changePlan` يلغي التراخيص الحالية ويصدر ترخيصاً جديداً؛ سجل الاشتراكات (عرض)
    - **تبويب «التراخيص والتفعيلات»:** زر «إعادة تعيين الأجهزة»؛ النقر على مفتاح الترخيص ← ينسخه للحافظة؛ سجل التفعيلات (عرض)
    - **تبويب «المدفوعات والفواتير»:** جداول عرض فقط (مدفوعات وفواتير العميل)
    - **تبويب «السجلات والنشاط»:** قوائم عرض فقط (سجل التغييرات، التفعيلات، النشاط)
    - **تبويب «مستخدمو العميل»:** زر «إضافة مستخدم» ← يفتح `UserModal`؛ أزرار صف: «تعديل» (Pencil) ← `UserModal`، «تعليق/تفعيل» (Ban/Check) ← `toggleUser`، «حذف» (Trash) ← `deleteUser`
    - **تبويب «التحكم عن بعد»:** زر «تحديث البيانات» و«تحديث» ← `loadRemoteControlData`؛ زر «مزامنة إجبارية» ← `forceSync`؛ خانات اختيار الأجهزة + زر تفعيل/إيقاف لكل جهاز (`toggleDeviceStatus`)؛ نموذج «إرسال إعدادات جديدة (Push Config)»: حقول المفتاح/القيمة/النطاق + زر «دفع التكوين» ← `pushConfig`؛ زر «تحديث السجل» لسجل دفع التكوين
  - **مودال «إضافة عميل جديد» (TenantFormModal — معالج):** مؤشر خطوات قابل للنقر للخطوات المكتملة؛ خطوات «بيانات المنشأة»، «بيانات التواصل»، «الباقة والحدود»، «حساب الدخول» (تُنشأ فقط عند الإضافة)، «المراجعة والحالة»؛ toggle «إنشاء حساب دخول»؛ أزرار «السابق / التالي / إضافة العميل / إلغاء»؛ عند التعديل: نموذج واحد + «حفظ التعديلات»
  - **مودال «تم إنشاء العميل بنجاح» (TenantCreatedModal):** زر «نسخ بيانات الدخول»/«تم النسخ»؛ خياران: «إعداد الصفحات والمميزات» ← يفتح `TenantCatalogWizard`، و«إنهاء» ← إغلاق
  - **مودال «الصفحات والمميزات» (TenantCatalogWizard):** 3 خطوات («الصفحات والوحدات»، «المميزات»، «المراجعة والتطبيق»)؛ toggle لكل وحدة/ميزة؛ زر «إعادة المحاولة» عند الخطأ؛ في المراجعة: قائمة «انحرافات عن الباقة»؛ أزرار «السابق / التالي / تطبيق التغييرات / إغلاق» ← `apply` يسجل tenant overrides
  - **مودال «إنشاء حساب للعميل» (AccountModal):** حقول اسم المستخدم/الاسم الكامل/البريد/كلمة المرور؛ أزرار «إلغاء / إنشاء الحساب» ← `createAccount`
  - **مودال «بيانات تفعيل العميل» (ActivationModal):** زر «نسخ كل البيانات»؛ «إعادة الإرسال» ← `sendActivation`؛ خانات اختيار قنوات الإرسال: «بريد إلكتروني / رسالة SMS / واتساب»؛ «إغلاق»
  - **مودال «إضافة/تعديل مستخدم» (UserModal):** حقول المستخدم والدور والحالة؛ أزرار «إلغاء / إضافة أو حفظ» ← `saveUser`
  - **مودال العمليات الجماعية (BulkActionModal):** عنوان يتغير حسب النوع («تغيير حالة/تغيير باقة/إرسال تفعيل/تصدير»)؛ حقل «الحالة الجديدة» أو «الباقة الجديدة + المدة» أو خانات قنوات الإرسال؛ زر التنفيذ: «تطبيق الحالة / تطبيق الباقة / إرسال التفعيل / تصدير» ← `executeBulkAction`؛ «إلغاء»
  - **مودال «استيراد عملاء من CSV» (CsvImportModal):** حقل اختيار ملف `.csv` مع معاينة أول 5 أسطر؛ زر «استيراد» ← `executeCsvImport`؛ «إلغاء»
  - **مودال «إضافة فرع للعميل» (BranchModal):** حقول الفرع + checkbox «الفرع الرئيسي للعميل»؛ أزرار «إلغاء / إضافة الفرع» ← `saveBranch`

## `/platform/licenses` — إدارة التراخيص
- **الملف:** `src/pages/platform/PlatformLicensesPage.tsx`
- **الوصف:** إصدار وتجديد وإيقاف وإلغاء تراخيص العملاء وربطها بالأجهزة (Hardware ID)، مع كشف استنساخ الأجهزة وتصدير تقارير CSV.
- **العناصر التفاعلية:**
  - زر «تصدير CSV» ← ينزّل `platform-licenses.csv`
  - زر «كشف الاستنساخ» ← `detectClones` (يعرض تنبيهات الاستنساخ في قسم مخصص)
  - زر «تقرير الامتثال» ← `exportCompliance` ينزّل `license-compliance.csv`
  - زر «إصدار ترخيص» ← يفتح مودال الإصدار
  - بحث + قائمة «كل الحالات» (صادر/نشط/موقوف/منتهي/ملغي) ← تصفية
  - إجراءات كل صف: «تجديد» (RefreshCw) ← مودال التجديد؛ «ربط جهاز» (Cpu) ← مودال ربط Hardware ID؛ «إيقاف/تفعيل» (Ban/Check) ← `changeStatus` مع تأكيد؛ «إلغاء» (ShieldX) ← `changeStatus(REVOKED)`؛ «تحرير الجهاز» (Link) ← مودال إجراء الجهاز (release)؛ «إيقاف الجهاز» (ShieldAlert) ← مودال إجراء الجهاز (suspend) — يظهران فقط عند وجود جهاز مربوط
  - **مودال «إصدار ترخيص جديد»:** قوائم العميل والخطة + حقول المدة/المستخدمين/الفروع/فترة السماح أوفلاين/نوع الربط + ملاحظات؛ أزرار «إلغاء / إصدار الترخيص» ← `issue`
  - **مودال «تجديد الترخيص»:** حقل «المدة (أشهر)»؛ أزرار «إلغاء / تجديد» ← `renew`

  - زر «توقيع التكوين وحفظه» ← `handleSaveConfig` (يتحقق من صياغة JSON ثم يحفظ/يعيد التوقيع)
  - قائمة «العميل المستهدف» ← تغيير العميل يعيد تحميل تكوينه وإصداراته
  - تبويبات: «محرر التكوين المركزي (JSON)»، «قوالب الأنشطة والخطط»، «النشر التدريجي والحملات»، «مقارنة النسخ (Diff)»، «سجل الإصدارات والاسترجاع»، «تأكيد استلام الأجهزة (ACK)»
  - تبويب المحرر: textarea JSON فقط (الحفظ عبر الزر العلوي)
  - تبويب القوالب: زر «استيراد هذا القالب إلى المحرر» على كل قالب ← `handleApplyTemplate` مع تأكيد (يستبدل محتوى المحرر)
  - تبويب النشر: نموذج إنشاء حملة (عنوان + قائمة «قالب التكوين» + قائمة «شريحة النشر المستهدفة»: كافة العملاء/نسبة تدريجية/بحسب النشاط/بحسب الباقة + حقل النسبة المئوية عند Canary) وزر «بدء النشر الآن» ← `handleCreateRollout` ينشئ الحملة ويبدأها فوراً
  - تبويب Diff: قائمتا اختيار «مقارنة الإصدار» و«الإصدار» ← يعرضان جدول الفروقات
  - تبويب السجل: زر «استرجاع وتطبيق» لكل إصدار غير نشط ← `handleRollback` مع تأكيد
  - تبويب ACK: جدول عرض فقط (معرف الجهاز، الإصدار، الحالة، التوقيت)

## `/platform/platform-health` — صحة المنصة والمراقبة التقنية
- **الملف:** `src/pages/platform/PlatformHealthPage.tsx`
- **الوصف:** صفحة مزدوجة حسب مصدر البيانات: في الوضع المركزي تعرض «مركز مراقبة الأخطاء» (بلاغات الأخطاء المُبلَّغة من الأجهزة مع تجميع بالبصمة وإجراءات إقرار/حل/تجاهل)، وفي الوضع المحلي تعرض لوحة صحة المنصة (مؤشرات تقنية + صحة أعمال).
- **العناصر التفاعلية:**
  - **الوضع المركزي (Error Monitoring):**
    - زر «تحديث» ← `load`
    - بطاقات الحالة الأربع «مفتوح / تم الإقرار / محلول / متجاهل» ← تبديل `errStatusFilter` (تصفية)
    - فلاتر: بحث نصي + قائمة «كل الحالات» + قائمة «كل الخطورات»
    - أزرار إجراءات لكل بلاغ: «إقرار» (OPEN فقط) ← `handleErrorAction(acknowledge)`؛ «حلّ» ← `resolve`؛ «تجاهل» ← `ignore`؛ «إعادة فتح» (RESOLVED/IGNORED) ← `reopen` — كلها عبر `centralPlatformClient.setErrorReportStatus`
  - **الوضع المحلي:**
    - زر «تحديث المؤشرات» ← `load`
    - فلاتر شدة التنبيهات: «الكل / حرج / تحذير / معلومات» ← `setAlertFilter`
    - رابط «معالجة» (ExternalLink) على كل تنبيه تقني له `alert.link` ← ينقل للصفحة المعنية
    - بقية البطاقات (المؤشرات التقنية، صحة الأعمال) عرض فقط
