# توثيق صفحات: التقارير — CRM — العملاء — المشاريع — لوحة التحكم

> توثيق لكل العناصر التفاعلية (أزرار، تبويبات، قوائم منسدلة، إجراءات الصفوف والمودالات) في الصفحات المذكورة. الصلاحيات مشروطة بصلاحيات `PermissionService.can` المذكورة في الكود.

## `/reports` — مركز التقارير والتحليلات

- **الملف:** `src/pages/reports/reports-hub/ReportsHubPage.tsx`
- **الوصف:** مركز موحّد يعرض ~55 تقريرًا مجمّعًا في 8 فئات (أساسية، حركة، مبيعات، ائتمان، مخزون، مالية، توقعات، موارد بشرية) مع بحث وفلترة بالصلاحيات ونشاط الأعمال.
- **المسارات المرتبطة:** `/reports` (كل الفئات)، `/reports/category/:categoryId` (فئة واحدة)، `/reports/:reportId` (تقرير محدد)، `?tab=sales|purchases|pos|finance|profitLoss|tax` (تقارير قديمة مدمجة)، `?category=` و`?report=` بدائل.
- **العناصر التفاعلية:**
  - حقل «ابحث عن تقرير…» ← يفلتر التقارير بالعنوان والوصف.
  - شرائح «موصى بها للنشاط» في الرأس ← كل شريحة تفتح تقريرها عبر `openReport` (يذهب إلى `/reports/:id` أو `?tab=` للتقارير القديمة).
  - زر/بطاقة «فتح التقرير» على كل بطاقة تقرير ← يفتح `/reports/:reportId`، أو `?tab=<legacyTab>` للتقارير القديمة الستة.
  - شارات الفئات (التقارير الأساسية، الحركة والعمليات، المبيعات والربحية، الائتمان والتحصيل، المخزون والمشتريات، المالية والخزينة، التوقعات والتحليل، الموارد البشرية) ← أقسام عرض فقط (الفئة تُحدد من الـ URL).
  - «مسح البحث» في حالة عدم وجود نتائج ← يصفّر البحث والفئة.
  - في وضع التقرير القديم (؟tab= أو /reports/:reportId لتقرير legacy): زر «مركز التقارير» بأيقونة السهم ← يعود إلى `/reports` أو `/reports/category/:id`.
- **ملاحظة:** التقارير القديمة الستة تُحمَّل كساكن (lazy) داخل نفس الصفحة عبر `LegacyReport` — انظر تفاصيل كل منها أدناه.

### `/reports/:reportId` — عرض تقرير عام (ReportView)

- **الملف:** `src/pages/reports/reports-hub/ReportView.tsx` (+ `reportCatalog.ts` يشغّل `ReportCenterService`)
- **الوصف:** شاشة تشغيل أي تقرير من الكتالوج: تاريخ/فترة، عناصر تحكم خاصة بالتقرير، KPIs، جدول قابل للفرز والبحث والتصدير، ورسم بياني اختياري.
- **العناصر التفاعلية:**
  - زر سهم «العودة لمركز التقارير» ← `onBack`.
  - زرّا «جدول» / «رسم بياني» ← تبديل العرض.
  - زر «فلترة متقدمة» ← يُظهر/يخفي لوحة فلاتر: الفرع، المخزن، الخزينة، العميل، المورد، الموظف، حالة الفاتورة، طريقة الدفع، مقارنة فرع + زر «مسح الفلاتر».
  - زر «تحديث» ← يعيد تشغيل التقرير (`refreshToken`).
  - زر «طباعة / PDF» ← `exportToPdf` بصلاحية `reports.export`.
  - زر «تصدير Excel» ← `exportToExcel` بصلاحية `reports.export`.
  - زر «CSV» ← تنزيل CSV بصلاحية `reports.export`.
  - أزرار الفترات الجاهزة: «اليوم / أمس / هذا الأسبوع / هذا الشهر / هذا الربع / هذا العام» ← تضبط نطاق التاريخ أو تاريخ «كما في».
  - عناصر تحكم التقرير (select «تجميع حسب»: المخزن/العميل/المندوب/الصنف، منتقي صنف `ProductPicker`، قائمة الخزائن) ← تُمرَّر إلى `runReport`.
  - حقل «بحث في النتائج…» ← يفلتر صفوف الجدول.
  - رؤوس الأعمدة في الجدول ← تنقر للفرز تصاعدي/تنازلي.
  - النقر على صف تقرير له `drilldown` ← toast يذكر المسار المقترح (مثل `/sales/invoices`، `/finance/cash-flow`، `/projects/execution` — لا ينتقل فعليًا).
  - أزرار الترقيم «السابق / التالي» وصفحة N من M ← ترقيم 50 صفًا.
- **التقارير المعرّفة في `reportDefinitions.ts`:** كل بطاقة تفتح `/reports/<id>` مثل: سجل العمليات، تقرير مستخدم، الحركة اليومية، الاستثناءات، الموافقات، التقارير الواردة، التنبيهات، تحليل المبيعات، مبيعات الأصناف، صنف مفصّل، ربحية الأصناف/العملاء، مقارنة الفترات، أعمار الديون، الائتمان والمتأخرات، سلوك الدفع، استحقاقات الشيكات، الشيكات المرتدة، أعمار الأقساط، المخزون، المخزون البطيء، تحليل المشتريات، أسعار الموردين، فروقات الجرد، المركز المالي، حركة الخزينة، تقفيل الورديات، التدفق النقدي المستقبلي، نقطة التعادل، أداء الفروع، أداء منشئي الفواتير، التدفق التفصيلي، التوقع والنفاد، العملاء اللي بيضيعوا، بيتباعوا مع بعض، تقارير سيراميك (3)، مستخلصات المشاريع، انحراف تكلفة المشاريع، التقارير اليومية للمواقع، ومجموعة تقارير HR (~30 تقريرًا) + تصنيع (4).

## التقارير القديمة المدمجة داخل `/reports?tab=`

### `?tab=tax` — تقرير ضريبة القيمة المضافة

- **الملف:** `src/pages/reports/tax-report/TaxReportPage.tsx` (يُعرض داخل `LegacyReport` في ReportsHubPage)
- **الوصف:** ملخص ضريبة المخرجات والمدخلات من فواتير البيع والشراء + تفصيل شهري. ليس إقرارًا ضريبيًا نهائيًا.
- **العناصر التفاعلية:**
  - «تصدير CSV» ← تنزيل `vat-report-<from>-to-<to>.csv`.
  - حقول «من تاريخ / إلى تاريخ» ← `FinanceExtrasService.getTaxSummary/getTaxByMonth`.

### `?tab=profitLoss` — قائمة الأرباح والخسائر

- **الملف:** `src/pages/reports/profit-loss/ProfitLossPage.tsx`
- **الوصف:** قائمة دخل تحليلية (إيرادات، تكلفة بضاعة، مصروفات، صافي ربح، هامش) + توزيع المصروفات + مصالحة مصروفات المصدر/الأستاذ عبر `AccountingService`.
- **العناصر التفاعلية:**
  - «تصدير CSV» ← تنزيل `profit-loss-<from>-to-<to>.csv`.
  - حقول «من تاريخ / إلى تاريخ».

### `?tab=finance` — القوائم المالية

- **الملف:** `src/pages/reports/financial-statements/FinancialStatementsPage.tsx` + `src/components/reports/financial-statements/*`
- **الوصف:** تبويبات القوائم المالية ببيانات `FinancialStatementsService` و`AccountingService`، كل تبويب بصلاحية خاصة.
- **العناصر التفاعلية:**
  - تبويبات (من `FinancialStatementsHeader`): «قائمة الدخل» (`income`)، «الميزانية العمومية» (`balance`)، «التدفقات النقدية» (`cash`)، «أعمار الديون» (`aging`)، «الأستاذ المساعد» (`subledger`)، «دفتر الأستاذ» (`ledger`)، «المصالحة» (`reconciliation`) — تظهر حسب الصلاحيات (`reports.profit_loss.view` / `reports.financial.view` / `finance.receivables.view`).
  - زر تحديث (أيقونة RefreshCw) ← `load` يعيد تحميل التبويب الحالي.
  - زر «جدول بيانات» ← تصدير التبويب الحالي إلى Excel (`reports.export`).
  - تبويب الميزانية: حقل تاريخ «كما في».
  - تبويبات الدخل/النقدية/الأستاذ/المساعد: حقول «من تاريخ / إلى تاريخ».
  - تبويب أعمار الديون: قائمة «العملاء / الموردون» + تاريخ.
  - تبويب الأستاذ المساعد: قائمة نوع الطرف «عميل/مورد» وقائمة الطرف ← `getPartyStatement`.
  - تبويب دفتر الأستاذ: قائمة الحسابات ← `getGeneralLedger`.

### `?tab=sales` — تقارير المبيعات المتقدمة

- **الملف:** `src/pages/reports/sales-reports/SalesReportsPage.tsx`
- **الوصف:** تقارير SQL مباشرة على `sales_invoices`/`sales_returns` مجمّعة حسب الفئة/الماركة/المنتج/العميل/المنطقة/المندوب/يوميًا + لوحة «مصالحة الفروقات المالية» (`SalesFinancialReconciliation`).
- **العناصر التفاعلية:**
  - تبويبات نوع التقرير: «حسب الفئة / حسب العلامة التجارية / حسب المنتج / حسب العميل / حسب المنطقة / حسب المندوب / تقرير يومي» ← تغيير `reportType`.
  - تبويب «مصالحة الفروقات المالية» ← يعرض `SalesFinancialReconciliation`: زر «تحديث الفحص»، حقول سبب الفرق (لمن يملك `finance.bank_reconciliation.close` + `ui.finance.overview.view`)، وزر «إقفال المراجعة وحفظها».
  - أزرار فترات سريعة: «هذا الشهر / هذه السنة / الأسبوع» + حقول «من/إلى».
  - زر «تصدير» ← `exportToExcel` بصلاحية `sales.export`.
  - زر تحديث (أيقونة RefreshCw).

### `?tab=pos` — تقارير نقطة البيع

- **الملف:** `src/pages/reports/pos-reports/PosReportsPage.tsx`
- **الوصف:** KPIs ليلية + توزيع طرق الدفع + توزيع بالساعة + أفضل 15 صنفًا + أداء منشئي الفواتير، ببيانات مباشرة من قاعدة البيانات (صلاحية `reports.view`).
- **العناصر التفاعلية:**
  - حقول «من/إلى» تاريخ + زر «تحديث».
  - رابط «جدول بيانات» بجانب «توزيع طرق الدفع» ← Excel `pos-payment-mix`.
  - رابط «جدول بيانات» بجانب «الأصناف الأكثر مبيعاً» ← Excel `pos-top-items`.

### `?tab=purchases` — تقارير المشتريات والمخزون

- **الملف:** `src/pages/reports/purchase-inventory/PurchaseInventoryReportPage.tsx`
- **الوصف:** تبويبات: المشتريات، الموردون، قيمة المخزون، المرتجعات — عبر `InventoryReportService`.
- **العناصر التفاعلية:**
  - زر «المشتريات» في الرأس ← ينتقل إلى `/purchases`.
  - زر تحديث (أيقونة RefreshCw).
  - تبويبات: «المشتريات / الموردون / قيمة المخزون / المرتجعات» (تظهر حسب `ui.reports.purchases.view`/`ui.inventory.valuation.view`).
  - أزرار «هذا الشهر / هذه السنة» + حقول تاريخ (مخفية في تبويب المخزون).
  - يتحدث تلقائيًا مع `DashboardRefreshContext`.

- **العناصر التفاعلية:**

- **الملف:** `src/pages/crm/crm-dashboard/CrmDashboardPage.tsx`
- **الوصف:** KPIs للمسار (إجمالي العملاء، قيمة Pipeline، معدل التحويل، متوسط الصفقة) + إجراءات سريعة + مخطط قمع + مصادر + أفضل المناديب + أحدث العملاء المحتملين. صلاحية `crm.view`.
- **العناصر التفاعلية:**
  - زر «العملاء المحتملون» ← `/crm/leads`.
  - زر «Pipeline» ← `/crm/pipeline`.
  - زر تحديث (أيقونة RefreshCw).
  - 4 بطاقات إجراءات: «متابعات متأخرة» ← `/crm/leads`، «أنشطة هذا الأسبوع» ← `/crm/activities`، «في مرحلة التفاوض» و«عروض أسعار مرسلة» ← `/crm/pipeline`.
  - زر «الكل» في «أحدث العملاء المحتملين» وعنصر كل عميل ← `/crm/leads`.
  - 4 بطاقات تنقّل: «إدارة العملاء المحتملين»، «Pipeline المبيعات»، «الأنشطة والمتابعة»، «الحملات التسويقية» ← المسارات المقابلة.

### `/crm/leads` — العملاء المحتملون

- **الملف:** `src/pages/crm/leads/LeadsPage.tsx`
- **الوصف:** بطاقات Leads ببحث وتصفية بالمرحلة + إنشاء/تعديل مرحلة/تحويل إلى عميل/حذف + حقول تشغيلية مخصصة (`OperationalFieldService`).
- **العناصر التفاعلية:**
  - زر «إضافة عميل محتمل» (صلاحية `ui.crm.leads.create`) ← مودال إنشاء: حفظ عبر `CrmService.createLead` + `fieldService.setRecordValues`، أزرار «إلغاء / حفظ».
  - حقل البحث + قائمة «جميع المراحل» + `OperationalFieldsFilter` ← تصفية فورية.
  - في كل بطاقة: قائمة اختيار المرحلة ← `service.updateLead(stage)` (صلاحية `ui.crm.leads.update`، مخفية عند WON).
  - زر سهم «تحويل إلى عميل مسجل» ← `convertLeadToCustomer` بتأكيد.
  - زر سلة «حذف العميل المحتمل» (صلاحية `ui.crm.leads.delete`) ← `deleteLead` بتأكيد.
  - زرّا اتصال (`tel:`) وبريد (`mailto:`).
  - `OperationalFieldsRecordEditor` على كل بطاقة ← تعديل الحقول الإضافية.

### `/crm/pipeline` — مسار المبيعات

- **الملف:** `src/pages/crm/pipeline/PipelinePage.tsx`
- **الوصف:** عرض كانبان بعمود لكل مرحلة (عميل محتمل → تم التواصل → مؤهل → عرض سعر → تفاوض → تم الإغلاق / خسارة).
- **العناصر التفاعلية:**
  - رابط «إدارة العملاء المحتملين» ← `/crm/leads`.
  - على بطاقة الفرصة (صلاحية `ui.crm.pipeline.update`): زرّا أسهم «مرحلة سابقة / مرحلة تالية» ← `service.updateLead` بتغيير `stage` للمرحلة المجاورة.

### `/crm/activities` — الأنشطة والمتابعات

- **الملف:** `src/pages/crm/crm-activities/CrmActivitiesPage.tsx` + `CrmActivityModal.tsx` + `crmActivityConfig.ts`

- **العناصر التفاعلية:**
  - زر «جدولة نشاط جديد» (صلاحية `ui.crm.activities.create`) ← مودال: حفظ عبر `service.createActivity`، أزرار «إلغاء / حفظ».
  - حقل البحث ← `service.getActivities(search)`.
  - زر «تحديد كمكتمل» على الأنشطة المعلقة (صلاحية `ui.crm.activities.update`) ← `service.completeActivity`.

### `/crm/campaigns` — الحملات التسويقية

- **الملف:** `src/pages/crm/campaigns/CampaignsPage.tsx`
- **الوصف:** بطاقات حملات بميزانية وقناة وعدد العملاء الناتجين — CRUD مباشر على جدول `campaigns`.
- **العناصر التفاعلية:**
  - زر «حملة جديدة» ← مودال إنشاء (INSERT بكود `CMP-XXXX` تلقائي).

## `/customers` — إدارة العملاء

- **الملف:** `src/components/customers/CustomersView.tsx` (مُصدَّر كـ `CustomersView` ويُستخدم أيضًا كتبويب داخل CRMHub)
- **الوصف:** جدول عملاء مرقّم + بطاقة كشف حساب جانبية + مودالا إضافة عميل وسند قبض.
- **العناصر التفاعلية:**
  - زر `ConfiguredActionButton` «إضافة عميل جديد» (إجراء `customers.create`) ← مودال: «إلغاء / حفظ العميل» عبر `customerService.createCustomer` + حقول تشغيلية.
  - حقل البحث «بالاسم، رقم الهاتف، أو كود العميل» + `OperationalFieldsFilter`.
  - النقر على صف العميل (بصلاحية كشف الحساب) ← يفتح كشف الحساب في البطاقة الجانبية.
  - رابط اسم العميل ← `/customers/:id` (صفحة تفاصيل).
  - زر أيقونة «فتح كشف الحساب» في عمود كشف الحساب.
  - في بطاقة العميل: زر «سند قبض / تحصيل» (`customers.payment`) ← مودال سند قبض: «إلغاء / اعتماد السند» عبر `customerService.recordPayment` (نقدي/بطاقة/تحويل بنكي مع حساب بنكي).
  - زر «تفعيل العميل / إيقاف العميل» (`customers.update`) ← `updateCustomer(isActive)` بتأكيد.
  - زر «حذف» (`customers.delete`) ← `deleteCustomer` بتأكيد.
  - ترقيم: «السابق / التالي» + حجم الصفحة (25/50/100).

  - زر «تعديل» (`partners.manage`) و«طباعة الكشف» (`partners.print` → `window.print`).
  - فلاتر الكشف: «من تاريخ / إلى تاريخ / نوع العملية / بحث في البيان» + زر «مسح».
  - زر «عكس» بجانب كل حركة (`partners.reverse`) ← مودال «عكس حركة شريك»: سبب العكس + «تأكيد العكس» عبر `reverseTransaction`.

  - تبويب سجل التوزيعات: زر «عرض الحصص / إخفاء» لكل دفعة ← يوسّع تفاصيل الحصص.
