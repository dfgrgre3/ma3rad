# توثيق صفحات المالية `/finance`

توثيق شامل لصفحات قسم المالية في تطبيق ERP (React + TypeScript). لكل صفحة: مسارها، وظيفتها، وكل العناصر التفاعلية (أزرار، تبويبات، عناصر قوائم، إجراءات الصفوف والمودالات) مع ما يفعله كل عنصر.

---

## `/finance` — المؤشرات المالية (نظرة عامة)
- **الملف:** `src/pages/finance/finance-overview/FinanceOverviewPage.tsx`
- **الوصف:** لوحة مؤشرات مالية لأداء الشهر الحالي (إيرادات، مصروفات، صافي ربح، ذمم، رصيد خزائن) مع مخطط أعمدة لآخر 6 أشهر. البيانات تُجلب عبر `queryFinanceOverviewMetrics` من `DashboardQueryScopeService`.
- **العناصر التفاعلية:**
  - زر التحديث (أيقونة `RefreshCw`) في ترويسة الصفحة ← يعيد تحميل البيانات (`loadData`).
  - بطاقات المؤشرات الست ← بطاقات عرض فقط (لا إجراءات): «إيرادات المبيعات (الشهر)»، «المصروفات والتشغيل (الشهر)»، «صافي أرباح المعرض»، «الذمم المدينة»، «الذمم الدائنة»، «رصيد الخزائن النقدية».
  - مخطط «تحليل الإيرادات والمصروفات الشهرية (آخر 6 أشهر)» ← tooltip تفاعلي عند تمرير المؤشر على الأعمدة فقط.

## `/finance/calendar` — التقويم المالي
- **الملف:** `src/pages/finance/financial-calendar/FinancialCalendarPage.tsx` + `FinancialEventsCalendar.tsx` ومجلد `FinancialEventsCalendar/` الفرعي
- **الوصف:** تقويم يجمع مواعيد الاستحقاق والتحصيل والسداد (فواتير عملاء/موردين، رواتب، أقساط، شيكات، مصروفات) في عرض شهري/أسبوعي/يومي مع تذكيرات ومرفقات ودفعات مرتبطة بالمصدر (`FinancialCalendarEventsService`).
- **العناصر التفاعلية:**
  - رابط «إدارة السنة المالية والإقفال» (أيقونة `LockKeyhole`) ← ينقل إلى `/finance/fiscal-closing` (يظهر لمن يملك `ui.finance.calendar.view`).
  - زر «حدث مالي جديد» ← يفتح مودال إنشاء حدث مالي (يتطلب `ui.finance.calendar.approve`).
  - زر تحديث الأحداث (أيقونة `RefreshCw`) ← يعيد تحميل الأحداث المالية.
  - زر «اليوم» وأزرار `ArrowRight`/`ArrowLeft` (الفترة السابقة/التالية) ← تنقل بين الشهور/الأسابيع/الأيام.
  - تبويبات العرض «شهري / أسبوعي / يومي» ← تغيّر `ViewMode` بين month/week/day.
  - قائمة الشهر ← ينتقل إلى شهر معين (وضع شهري فقط).
  - قائمة السنة ← ينتقل إلى سنة معينة (وضع شهري فقط).
  - زر رقم اليوم في الشبكة / زر عنوان اليوم في العرض المحمول ← يحدد اليوم ويبدّل إلى العرض اليومي.
  - زر `+` على كل خلية يوم (يظهر لمن يملك `canManage`) ← يفتح مودال حدث مالي جديد بتاريخ ذلك اليوم.
  - أزرار الأحداث `EventButton` (كل حدث) ← تفتح مودال «تفاصيل الحدث المالي».
  - زر «+N أحداث أخرى» داخل اليوم المكتظ ← يحدد ذلك اليوم ويبدّل إلى العرض اليومي.
  - بطاقة حدث في العرض اليومي (الزر بعنوان الحدث) ← تفتح مودال التفاصيل.
  - **FilterPanel — تصفية الأحداث:**
    - حقل «انتقل إلى يوم» (تاريخ) ← يقفز التقويم ليوم محدد (محمول).
    - حقل بحث «بحث بالعنوان أو الطرف أو المرجع» ← يصفّي الأحداث بالعنوان/الطرف/المرجع/الوصف.
    - قائمة «نوع الحدث» ← تصفية حسب نوع الحدث (كل أنواع الأحداث، خيار فاتورة عميل، فاتورة مورد، راتب، قسط، مصروف، يدوي...).
    - قائمة «حالة الحدث» ← تصفية حسب الحالة (مجدول، مستحق اليوم، مدفوع، محصل، متأخر، ملغي، جزئيًا...).
    - قائمة «نوع الطرف» ← عميل/مورد/موظف/أخرى.
    - قائمة «العميل أو المورد» ← اختيار طرف محدد (عميل/مورد/موظف حسب نوع الطرف).
    - قائمة «الحساب المالي» ← تصفية حسب الحساب المالي.
    - قائمة «العملة» ← تصفية حسب العملة.
    - حقول «من مبلغ»/«إلى مبلغ» و«من تاريخ»/«إلى تاريخ» ← تصفية بمدى المبلغ والتاريخ.
    - زر «إلغاء نطاق التاريخ» (يظهر عند وجود نطاق) ← يصفّر فترتي التاريخ.
    - قائمة «التقرير المالي» ← اختيار قالب التقرير للتصدير (كل التقارير، دخل، مصروفات، قادمة، متأخرة، عملاء، موردون...).
    - زرا «Excel» و«PDF» ← يصدّر التقريران بـ `exportToExcel`/`exportToPdf` (يتطلب `ui.finance.calendar.export`).
  - **مودال «إضافة/تعديل حدث مالي» (`EventFormModal`):**
    - زر «حفظ الحدث» ← يحفظ/يحدّث الحدث عبر `service.saveEvent` (يدعم إنشاء وتعديل).
    - زر «إلغاء» وأيقونة إغلاق المودال ← يغلق المودال.
    - (حقول النموذج: عنوان، نوع، مبلغ، عملة، استحقاق، تذكير بموعد و/أو قبلها 7/3/1 يوم، نوع الطرف والطرف المرتبط، حساب مالي، مرجع، وصف — حقول إدخال فقط.)
  - **مودال «تفاصيل الحدث المالي» (`EventDetailsModal`):**
    - زر «تسجيل تحصيل» أو «تسجيل دفعة» (حسب `isIncome`، يتطلب صلاحية الدفع المعنية) ← يفتح مودال الدفعة.
    - زر «تأجيل الاستحقاق» (أحداث يدوية فقط) ← يفتح مودال إعادة الجدولة.
    - زر «إرفاق مستند» ← يفتح مودال اختيار الملف.
    - زر «تعديل» ← يفتح مودال تعديل الحدث في `EventFormModal`.
    - زر «إلغاء الحدث» ← يطلب تأكيداً ثم `service.cancelEvent`.
    - روابط المرفقات ← تحميل الملف المحلي (download).
  - **مودال «تسجيل تحصيل / تسجيل دفعة» (`PaymentModal`):**
    - زر «تأكيد العملية» ← يسجّل الدفعة عبر `service.recordPayment` (يحدّث الحالة تلقائياً مدفوع/محصل/جزئي).
    - زر «إلغاء» وأيقونة الإغلاق ← يغلق المودال.
  - **مودال «تأجيل تاريخ الاستحقاق» (`RescheduleModal`):**
    - زر «حفظ الموعد» ← `service.reschedule` بتاريخ الاستحقاق الجديد.
    - زر «إلغاء» وأيقونة الإغلاق ← يغلق المودال.
  - **مودال «إرفاق مستند» (`AttachmentModal`):**
    - منطقة اختيار الملف (أو صورة/PDF/Word/Excel حتى 5 ميجابايت) ← `service.addAttachment` بعد اختيار الملف.
    - (الضغط على الخلفية أو إغلاق المودال يلغيه.)
  - تنبيهات التذكير المالية تظهر تلقائياً كـ toast («مستحق اليوم»، «تذكير مالي»، «لديك N أحداث مالية أخرى»).

## `/finance/receivables` — مركز الذمم والتحصيل
- **الملف:** `src/pages/finance/receivables-hub/ReceivablesHubPage.tsx`
- **الوصف:** صفحة تجمع ثلاثة أقسام تحت تبويبات موحدة حسب الصلاحية: ديون العملاء والموردين، المطالبات الأخرى، الأقسام، وقسم متابعة مركّب. تخدم أيضًا `/finance/other-receivables` (تبويب `other`) و`/finance/installments` (تبويب `installments`) و`/finance/debts` (تحويل إلى `?tab=debts`).
- **العناصر التفاعلية:**
  - أزرار التبويبات: «ديون العملاء والموردين» ← يعرض `DebtsDashboardPage`؛ «المطالبات الأخرى» ← يعرض `OtherReceivablesPage`؛ «الأقساط» ← يعرض `InstallmentsPage`؛ «التحصيل والمتابعة» ← يعرض شاشة اختيار المصدر (كل تبويب يظهر فقط إن كان مساره مسموحًا بصلاحية المستخدم).
  - في تبويب «التحصيل والمتابعة»: زر «متابعة تحصيل العملاء والموردين» ← ينقل إلى تبويب `debts`؛ زر «متابعة الأقساط» ← ينقل إلى تبويب `installments`.
  - ملاحظة: إذا لم يملك المستخدم أي قسم يظهر نص «لا تملك صلاحية لأي قسم من مركز الذمم.»

## `/finance/other-receivables` — المستحقات الأخرى (تبويب «المطالبات الأخرى»)
- **الملف:** `src/pages/finance/other-receivables/OtherReceivablesPage.tsx`
- **الوصف:** إدارة المستحقات المالية وغير المالية المستقلة عن الفواتير (جدول `receivables` مع سجل تحديثات ومرفقات)، مع تصفية وحالة وإنجاز لكل بند. تُعرض داخل مركز الذمم على مسار `/finance/other-receivables`.
- **العناصر التفاعلية:**
  - زر «جدول بيانات» ← يصدّر تقرير «تقرير المستحقات الأخرى المفتوحة» إلى Excel (`exportToExcel`).
  - زر «طباعة / مستند» ← نفس التقرير بصيغة PDF (`exportToPdf`).
  - زر «مستحق جديد» ← يفتح مودال «تسجيل مستحق» (يكتب `finance.receivables.create`).
  - حقل بحث «ابحث بالوصف أو الجهة أو الهاتف» ← يصفّي البطاقات محليًا.
  - قائمة «الحالة» (المفتوحة/مكتملة/ملغاة/كل الحالات) و«النوع» (كل الأنواع + الأنواع الموجودة) وتاريخا «من/إلى الاستحقاق» ← تصفية البطاقات.
  - قائمة حالة كل بطاقة (مفتوح/جارٍ/مكتمل/ملغي حسب الصلاحية) ← تحديث `status` عبر `update()` مع تسجيل `STATUS` في `receivable_updates`.
  - حقل «نسبة الإنجاز» (%، تُحفظ عند blur) ← تحديث `progress` عبر `update()`.
  - زر «تعديل» (أيقونة قلم) ← يفتح مودال «تعديل المستحق» معبأ ببيانات البطاقة.
  - زر «السجل» (أيقونة `History`) ← يعرض/يخفي سجل `receivable_updates` للبطاقة.
  - زر «المرفقات» (أيقونة `Download`) ← يعرض/يخفي مرفقات `receivable_attachments`؛ كل اسم ملف زر يحذف/ينزّل المرفق محليًا.
  - **مودال «تسجيل/تعديل مستحق»:**
    - زر «حفظ» ← ينشئ/يحدّث السجل + سجل تحديث + مرفقات جديدة + سجل تدقيق (`finance.receivables.create/update`).
    - زر «إلغاء» ← يغلق المودال ويعيد ضبط النموذج.

## `/finance/installments` — الأقساط (تبويب «الأقساط»)
- **الملف:** `src/pages/finance/installments/InstallmentsPage.tsx`
- **الوصف:** إنشاء خطط تقسيط لعملاء من فواتيرهم المفتوحة، تسجيل سداد الأقساط بالخزينة، ومتابعة المتأخرة (خدمة `InstallmentService`).
- **العناصر التفاعلية:**
  - زر «إنشاء خطة تقسيط جديدة» ← يفتح مودال إنشاء الخطة (يتطلب `ui.finance.installments.manage`).
  - حقل بحث «بحث باسم العميل أو رقم الخطة...» ← يصفّي الأقساط.
  - قائمة «الحالة» (جميع الحالات/متأخر عن موعده/قادم ومستحق/مسدد بالكامل) ← تصفية حسب `status`.
  - بطاقة القسط غير المسدد — زر «تسجيل سداد القسط بالخزينة» ← طلب تأكيد ثم `installmentService.payInstallment` (يضيف المبلغ للخزينة ويولّد إيصالًا).
  - بطاقة القسط المسدد — زر «عكس السداد» ← تأكيد ثم `reverseInstallmentPayment` (يعيد الدين لرصيد العميل، يتطلب `canManage`).
  - زر «إلغاء الخطة» (يظهر فقط على القسط الأول، `canManage`) ← تأكيد ثم `cancelPlan` (يعكس المقدم إن وجد).
  - **مودال «إنشاء خطة تقسيط جديدة لعميل»:**
    - حقل «اختر العميل» وقائمة «اختر الفاتورة ذات الرصيد المستحق» ← اختيار العميل ثم فاتورته (يملأ إجمالي التمويل تلقائيًا).
    - حقل «الدفعة المقدمة» و«عدد الأقساط» (3/6/10/12/24 شهرًا) و«تاريخ أول قسط» ← مدخلات الخطة.
    - زر «تأكيد وإنشاء خطة الأقساط» ← `installmentService.createPlan` مع توليد الأقساط وإيصال المقدم.
    - زر «إلغاء» وأيقونة ✕ ← إغلاق المودال.

## `/finance/debts` — الديون والذمم المالية (تبويب «ديون العملاء والموردين»، توجيه `?tab=debts`)
- **الملف:** `src/pages/finance/debts-dashboard/DebtsDashboardPage.tsx` ومجلد `DebtsDashboardPage/` الفرعي
- **الوصف:** بطاقات مديونية لكل عميل (ذمم مدينة) ومورد (مستحقات دائنون) مع ملخص إجمالي ومؤشرات، وتوسيع بطاقة العميل لعرض فواتيره ومدفوعاته ووعده السداد، وتسجيل التحصيل/السداد، وعكس السندات.
- **العناصر التفاعلية:**
  - بطاقات الملخص الثلاث (ذمم مدينة، مستحقات للموردين، صافي المركز) ← عرض فقط.
  - بطاقات المؤشرات الست (في `MetricCards.tsx`):
    - «عملاء بأرصدة مدينة»، «فواتير غير مسددة بالكامل»، «مبالغ الفواتير المتأخرة» ← تصفير حقل البحث (`onResetSearch`).
    - «قيمة البضائع المنتظرة»، «توريدات متأخرة» ← تنقل إلى `/purchases/incoming`.
    - «مستحقات أخرى مفتوحة» ← تنقل إلى `/finance/other-receivables`.
  - حقل بحث «بحث باسم الحساب ثم اضغط إدخال...» ← يصفّي/يبحث في `DebtService.getDebtsAsync`.
  - زر «تقرير المتأخرات بصيغة جدول بيانات» ← تصدير تقرير الفواتير المتأخرة إلى Excel (`reports.export`).
  - زر «طباعة التقرير» ← نفس التقرير بصيغة PDF.
  - بطاقة الدين — زر «تفاصيل الفواتير والأصناف» (للعملاء فقط) ← توسيع/طي تفاصيل العميل (`fetchCustomerDetails`).
  - داخل البطاقة الموسّعة: زر «تسجيل وعد سداد / متابعة» ← يفتح مودال «وعد السداد والمتابعة» (يتطلب `ui.customers.list.update`).
  - زر «تصدير كشف في جدول بيانات» ← تصدير كشف حساب العميل إلى Excel (`customers.export`).
  - زر «طباعة / مستند» ← كشف الحساب بصيغة PDF.
  - رابط «عكس السند» بجانب كل دفعة مسجلة (يتطلب `customers.payment.reverse`) ← تأكيد ثم حذف الدفع (`SalesService.deleteInvoicePayment` أو `CustomerService.deletePayment`).
  - زر «تسجيل تحصيل» (للعملاء) أو «سداد دفعة» (للموردين) أسفل البطاقة ← يفتح مودال الدفع.
  - **مودال «تسجيل تحصيل / سداد دفعة» (`PaymentModal`):**
    - حقول توزيع الدفعة على الفواتير المفتوحة (لعملاء ذمم مستحقة)، أو حقل «المبلغ» عند عدم وجود فواتير/مورد.
    - قائمة «طريقة الدفع» (نقدي/بطاقة/تحويل بنكي) وحقل «تاريخ الدفع» و«المرجع / الملاحظات» (لتحصيل العملاء).
    - زر «تأكيد» ← `SalesService.recordCustomerPaymentAllocations` / `CustomerService.recordPayment` / `SupplierService.recordPayment` بعد التحقق من المبالغ.
    - زر «إلغاء» وأيقونة `X` ← إغلاق المودال.
  - **مودال «وعد السداد والمتابعة» (`PromiseModal`):**
    - زر «حفظ» ← `recordPaymentPromise` تسجيل وعد السداد (مبلغ/تاريخ وعد/متابعة/ملاحظات) ويحدّث تفاصيل العميل.
    - زر «إلغاء» ← إغلاق المودال.

## `/finance/expenses` — إدارة المصروفات التشغيلية (و `/daily/expenses` كـ `TodayExpensesPage`)
- **الملف:** `src/pages/finance/expenses/ExpensesPage.tsx` + `src/components/daily/ExpenseModal.tsx` + hooks `useExpenseCategories`/`useRegisters`
- **الوصف:** سجل المصروفات التشغيلية ببحث وتصفية تاريخية (نطاق في `/finance/expenses`، يوم واحد في `/daily/expenses`)، مع عدادات وتصدير وتعديل/حذف. البيانات عبر `CashierService.getAllExpenses`.
- **العناصر التفاعلية:**
  - زر «تصدير» ← تصدير المصروفات المصفاة إلى Excel (`exportToExcel`).
  - زر «تسجيل مصروف جديد» ← يفتح `ExpenseModal` (يتطلب `ui.cashier.expenses.expense`).
  - حقل بحث «بحث بالبند أو البيان...» ← يصفّي الجدول محليًا.
  - حقلا «من/إلى» تاريخ (في نمط range فقط) ← يحددان نطاق المصروفات.
  - أيقونة قلم «تعديل مصروف» (يتطلب `cashier.expense.update`) ← يفتح `ExpenseModal` مملوءًا.
  - أيقونة سلة «حذف مصروف» (يتطلب `cashier.expense.delete`) ← تأكيد ثم `service.deleteExpense`.
  - **مودال `ExpenseModal` («إضافة/تعديل مصروف»):**
    - زر «حفظ» ← `service.addExpense` أو `service.updateExpense` (يخصم من الخزينة المحددة).
    - زر «إلغاء» وأيقونة الإغلاق ← يغلق المودال.
    - (حقول: البند، المبلغ، البيان، المستفيد، طريقة الدفع نقدي/بنكي، الخزينة.)
