# توثيق صفحات العمليات (Operations)

توثيق تفاعلي لعناصر التحكم في صفحات قسم العمليات. كل قسم يشرح الوظيفة والأزرار والعناصر القابلة للنقر.

---

## `/branches` — إدارة الفروع والمعارض
- **الملف:** `src/pages/operations/branches/BranchesPage.tsx`
- **الوصف:** عرض فروع الشركة كالبطاقات مع بيانات كل فرع (عنوان، هاتف، شركة مالكة، مسؤول، مخازن، جهاز مزامنة) مع إمكانية البحث والتصفية حسب الحالة.
- **العناصر التفاعلية:**
  - زر «تحديث» ← يعيد تحميل الفروع والإحصائيات.
  - زر «إضافة فرع» ← يفتح مودال إضافة فرع جديد (يُحجب إن تجاوز حد الفروع المسموح `maxBranches` أو لا توجد صلاحية الإنشاء).
  - حقل بحث (بالاسم/الكود/المدينة/العنوان) + فلتر حالة (كل الحالات/النشطة/المعطلة) ← يصفّي القائمة.
  - «الأداة» (OperationalFieldsFilter) ← تصفية الفروع حسب الحقول المخصصة.
  - محرر «الحقول المخصصة» على كل بطاقة فرع ← يفتح محررًا لحفظ قيم حقول إضافية على الفرع.
  - رابط الهاتف في البطاقة ← يفتح `tel:`.
  - في حالة أن الفرع هو **الفرع النشط الحالي**: أزرار «التفاصيل»، «تعديل»، «المخازن»، «المستخدمون» ← تفتح مودال إدارة الفرع بتبويب معيّن (نظرة عامة / مخازن / مستخدمون)، أو مودال تعديل.
  - في حالة فرع **نشط آخر غير حالي**: زر «التبديل إلى هذا الفرع» ← يعيّنه فرعًا حاليًا ويعيد تحميل الصفحة.
  - زر «تفعيل»/«تعطيل» ← يغيّر حالة الفرع (معطّل للفرع الافتراضي أو للفرع النشط غير الحالي).
  - زر «إضافة أول فرع» في حالة القائمة الفارغة ← يفتح مودال الإضافة.
  - **مودال «إضافة فرع جديد» / «تعديل بيانات الفرع»:**
    - زر «إلغاء» ← يغلق المودال؛ زر «إنشاء الفرع»/«حفظ التعديلات» ← يحفظ ويعرض رمز التفعيل للفرع الجديد.
  - **مودال إدارة الفرع (wide):**
    - تبويبات «نظرة عامة»، «المخازن»، «مستخدمو الفرع» ← تبديل المحتوى.
    - في تبويب «المخازن»: اختيار مخزن + checkbox «مخزن أساسي» + زر «ربط المخزن» ← ربط مخزن متاح بالفرع؛ أيقونة X على كل مخزن مربوط ← إلغاء الربط.
    - في تبويب «مستخدمو الفرع»: checkboxes لاختيار المستخدمين المربوطين + زر «حفظ إسناد المستخدمين» ← يحفظ إسناد المستخدمين للفرع.

## `/warehouses` — المخازن والمستودعات
- **الملف:** `src/pages/operations/warehouses/WarehousesPage.tsx`
- **الوصف:** بطاقات المخازن مع مؤشرات المخزون (رصيد، متاح، محجوز، قيمة، أصناف ناقصة) وبطاقات إحصائية إجمالية على مستوى النظام.
- **العناصر التفاعلية:**
  - زر «إضافة مخزن جديد» ← يفتح مودال إضافة/تعديل مخزن (مشروط بصلاحية `warehouses.manage` وحد `maxWarehouses`).
  - حقل بحث (اسم/عنوان + Enter) ← يعيد تحميل القائمة؛ و«الأداة» (OperationalFieldsFilter) ← تصفية حسب الحقول المخصصة.
  - في كل بطاقة مخزن: قائمة «نوع المستودع» ← تغيير نوع المخزن مباشرة (`updateWarehouseType`).
  - محرر «الحقول المخصصة» ← حفظ حقول إضافية على المخزن.
  - زر «تعديل» ← يفتح مودال تعديل المخزن.
  - زر «نقل الرصيد» (يظهر فقط إن كان للمخزن رصيد وصلاحية `inventory.hub.transfer`) ← يفتح مودال «طلب نقل الرصيد قبل تعطيل المخزن»؛ فيه اختيار المخزن المستهدف وزر «إنشاء طلب نقل» ← ينشئ طلب تحويل مخزني ويبقي المخزن نشطًا حتى اكتمال التحويل.
  - زر «تعيين افتراضي» ← يجعل المخزن افتراضيًا.
  - زر «تعطيل»/«إعادة تفعيل» ← يغيّر حالة المخزن (التعطيل معطّل إن كان به رصيد).
  - **مودال إضافة/تعديل المخزن:** زر «إلغاء» و«إضافة»/«حفظ التعديلات» ← حفظ.
  - **مودال نقل الرصيد:** زر «إلغاء» و«إنشاء طلب نقل» ← إنشاء طلب النقل.

## `/fleet/dashboard` — لوحة تحكم التوصيل والأسطول
- **الملف:** `src/pages/operations/fleet-dashboard/FleetDashboardPage.tsx`
- **الوصف:** لوحة KPI لأسطول التوصيل: عدد التوصيلات، إيرادات التوصيل، السائقون النشطون، التوصيلات الفاشلة، وأداء السائقين.
- **العناصر التفاعلية:**
  - زر «التوصيلات» ← ينقل إلى `/deliveries`.
  - زر «السائقون» ← ينقل إلى `/drivers`.
  - أيقونة تحديث (RefreshCw) ← يعيد تحميل الإحصائيات.
  - زر «الكل» في قسم «أحدث التوصيلات» ← ينقل إلى `/deliveries`.
  - بطاقة تنقّل «أوامر التوصيل» ← `/deliveries`؛ «السائقون» ← `/drivers`؛ «المركبات» ← `/vehicles`.

## `/facility-management` — المرافق والأصول التشغيلية
- **الملف:** `src/pages/operations/facility-management/FacilityManagementPage.tsx`
- **الوصف:** إدارة كاملة للمواقع والمنشآت، الأصول التشغيلية، أوامر الصيانة، العقود، وسجلات السلامة مع دورات حياة.
- **العناصر التفاعلية:**
  - زر تحديث (RefreshCw) ← يعيد تحميل كل البيانات.
  - زر «إضافة موقع/أصل/طلب صيانة/عقد/سجل سلامة» ← يفتح مودال الإضافة بحسب التبويب النشط.
  - تبويبات: «المواقع والمنشآت»، «الأصول التشغيلية»، «الصيانة وأوامر العمل»، «العقود والخدمات»، «التفتيش والسلامة» ← تبديل الأقسام (مع تصفير البحث).
  - حقل «بحث في السجلات» ← يصفّي سجلات التبويب الحالي.
  - **جدول المواقع:** زر تعديل (قلم) ← مودال تعديل الموقع؛ زر أرشفة (أرشيف) ← أرشفة الموقع؛ زر استعادة (Store) للمواقع المؤرشفة.
  - **جدول الأصول:** زر تعديل؛ زر أرشفة؛ زر استبعاد (Trash2) ← استبعاد الأصل؛ زر استعادة للأصول المستبعدة.
  - **أوامر العمل:** زر «اعتماد» (مفعّل فقط للحالة OPEN)؛ أيقونة History (تفاصيل الدورة)؛ زر «بدء» (APPROVED فقط)؛ زر «إكمال» (IN_PROGRESS فقط)؛ أيقونة إعادة فتح (COMPLETED فقط)؛ زر أرشفة.
  - **قسم «جداول الصيانة الوقائية»:** زر «إنشاء أمر مستحق» على الجدولة المستحقة ← ينشئ أمر عمل وقائي.
  - **جدول العقود:** زر تعديل لكل عقد.
  - **سجلات السلامة:** زر «إغلاق» (تحديد كمعالجة) للسجلات غير المغلقة.
  - **مودال إضافة/تعديل سجل:** زر «إلغاء» وزر «حفظ السجل»/«حفظ التعديل» ← حفظ في الخدمة المناسبة.
  - **مودال تفاصيل أمر العمل:** أزرار «اعتماد الأمر»، «بدء التنفيذ»، «إكمال الأمر مع فحص الجودة»، «إعادة فتح الأمر» (يطلب سببًا عبر prompt) حسب الحالة؛ زر «إدارة المرفقات» (placeholder — لا يعمل بعد)؛ أيقونة Trash على كل مرفق ← حذفه؛ زر «إغلاق».

## `/deliveries` — أوامر التسليم
- **الملف:** `src/pages/operations/deliveries/DeliveriesPage.tsx`
- **الوصف:** جدول أوامر التسليم/الشحنات مع البحث والفلترة حسب الحالة وإجراءات دورة التوصيل.
- **العناصر التفاعلية:**
  - زر «أمر تسليم جديد» ← يفتح مودال إنشاء أمر (مشروط بصلاحية `deliveries.create`).
  - حقل بحث (رقم الأمر/العميل/العنوان) + قائمة «كل الحالات» ← تصفية الجدول.
  - زر «تعبئة/فحص» في كل صف ← يفتح `DeliveryDetailModal`.
  - زر «بدء التوصيل» (PENDING/SCHEDULED) أو «تأكيد التسليم» (IN_TRANSIT) ← يقدّم حالة الأمر (مشروط بصلاحيات `deliveries.start`/`complete`).
  - زر «إلغاء» ← يلغي الأمر بعد تأكيد (صالحية `deliveries.cancel`).
  - **مودال «أمر تسليم جديد» (`DeliveryCreateModal`):** اختيار العميل يملأ العنوان والمدينة تلقائيًا؛ اختيار السائق والمركبة؛ زر «إلغاء» و«إنشاء» ← ينشئ الأمر.
  - **مودال «تعبئة وفحص ما قبل الشحن» (`DeliveryDetailModal`):**
    - اختيار المنتج/الكمية/الكراتين/التشغيلة/الدفعة + زر «إضافة بند» ← إضافة بند تعبئة.
    - أيقونة Trash على كل بند ← حذفه.
    - checkbox «يتطلب فحص ما قبل الشحن قبل الإرسال» ← تفعيل متطلب QC.
    - اختيار نتيجة الفحص (ناجح/مشروط/راسب) + checkboxes «التغليف سليم» و«الكميات مطابقة» + زر «تسجيل الفحص» ← تسجيل نتيجة QC.
    - زر X في الأعلى ← إغلاق المودال (ينقر على الخلفية أيضًا يغلقه).

## `/employees` — إدارة شؤون وأجور العمال
- **الملف:** `src/pages/operations/employees/EmployeesPage.tsx` (+ مكونات `employees/` الفرعية)
- **الوصف:** صفحة شؤون الموظفين/العمال بأربعة تبويبات: دليل العمال، حسابات الأجور والرواتب، سجل الحضور اليومي، وتقارير التحليلات.
- **العناصر التفاعلية:**
  - زر «إضافة عامل / موظف جديد» ← يفتح `EmployeeFormModal` (يُحجب بحد `maxEmployees`).
  - زر «تصدير» ← يصدّر الموظفين إلى Excel (صلاحية `employees.export`).
  - زر «إعادة المحاولة» في رسالة الخطأ ← يعيد تحميل البيانات.
  - تبويبات: «دليل العمال وتوزيعهم»، «حسابات الأجور والرواتب» (يتطلب `employees.manage`)، «سجل الحضور اليومي» (يتطلب `employees.attendance.view`)، «تقارير المراقبة والتحليلات» (يتطلب `employees.manage`).
  - شريط بحث + فلتر «حسب موقع العمل» + حقل «تاريخ الحضور» (في تبويب الحضور فقط) ← تصفية.
  - **تبويب الدليل:** أيقونة تعديل (قلم) على بطاقة الموظف ← يفتح مودال التعديل؛ زر «السجل المالي» ← يفتح `EmployeeHistoryModal`؛ محرر الحقول المخصصة؛ روابط الهاتف/البريد `tel:`/`mailto:`.
  - **تبويب الحسابات المالية:** حقل «فترة الاستحقاق» (شهر) ← يغيّر الفترة؛ زر «تسجيل حركة مالية» على كل موظف ← يفتح `EmployeeTransactionModal`؛ أيقونة FileText ← يفتح `EmployeeHistoryModal`.
  - **تبويب الحضور:** زر «فتح سجل الوقت والورديات» ← ينقل إلى `/employees/attendance`؛ أزرار «حاضر»، «متأخر»، «غائب»، «إجازة» لكل موظف ← تسجيل/تعديل حالة الحضور (قد تذهب للموافقة).
  - **تبويب التحليلات:** عروض إحصائية ثابتة (توزيع المواقع، أنواع الرواتب، الحالات، أحدث الحركات) — بلا أزرار.
  - **مودال الموظف (`EmployeeFormModal`):** أزرار «+ إضافة مسمى»، «تعديل المحفوظ»، «تعطيل المحفوظ» (للمسمى الوظيفي)؛ «+ إضافة قسم»، «تعديل المحدد»، «تعطيل المحدد» (للقسم)؛ checkbox «مندوب مبيعات» يعرض حقول العمولة/المستهدف/الفروع الإضافية؛ أزرار «إلغاء» و«إضافة الموظف»/«حفظ التغييرات».
  - **مودال الحركة المالية (`EmployeeTransactionModal`):** اختيار نوع الحركة (سلفة/مكافأة/خصم/صرف راتب)؛ زر «إلغاء» و«تسجيل الحركة المالية».
  - **مودال السجل المالي (`EmployeeHistoryModal`):** أيقونة Trash على كل معاملة ← حذفها بعد تأكيد؛ زر «إغلاق».

## `/employees/attendance` — الحضور والانصراف
- **الملف:** `src/pages/operations/attendance/AttendancePage.tsx`
- **الوصف:** سجل حضور يومي مع ورديات، استراحات، تصحيحات معتمدة، كشف شهري، واستيراد بصمة CSV.
- **العناصر التفاعلية:**
  - تبويبات: «اليومي»، «الورديات والجداول»، «الكشف الشهري»، «التصحيحات والتدقيق»، «استيراد البصمة».
  - زر «تسجيل غير المسجلين حاضرين» (في تبويب اليومي مع صلاحية manage) ← يسجّل كل الموظفين غير المسجلين «حاضر» لليوم.
  - تبويب «اليومي»: حقل التاريخ + بحث الموظف؛ في كل صف: أزرار «دخول»، «انصراف»، «استراحة»، «إنهاء الاستراحة»، «اعتماد الإضافي» ← عمليات البصمة والاعتماد؛ details «طلب تعديل» ← نموذج تصحيح يدوي + زر «إرسال للموافقة».
  - تبويب «الورديات والجداول»: نموذج «إنشاء وردية» + زر «حفظ الوردية»؛ قسم «تعيين وردية لموظف» + زر «تعيين الوردية»؛ قسم «العطلات الرسمية للفرع» + زر «إضافة عطلة» + زر «حذف» على كل عطلة.
  - تبويب «الكشف الشهري»: حقل الشهر؛ زر «تصدير CSV»؛ زر «طباعة الكشف».
  - تبويب «التصحيحات والتدقيق»: أزرار «اعتماد»/«رفض» على طلبات التصحيح المعلقة (صلاحية approve).
  - تبويب «استيراد البصمة»: زر «تنزيل القالب» + حقل اختيار ملف CSV ← استيراد سجلات البصمة (قد تنشئ طلبات تصحيح).

## `/employees/payroll` — الرواتب والمسحوبات
- **الملف:** `src/pages/operations/payroll/PayrollPage.tsx`
- **الوصف:** دورة رواتب شهرية (احتساب، اعتماد، صرف جماعي، إغلاق) مع حركات إضافية للموظفين وكشف آخر الحركات.
- **العناصر التفاعلية:**
  - حقل «فترة الرواتب» (شهر) ← يبدّل الدورة.
  - زر «احتساب الرواتب»/«إعادة الاحتساب» ← إنشاء/إعادة حساب مسودة الرواتب (مشروط بـ `payroll.manage`).
  - زر «تصدير CSV» ← تصدير بنود الدورة للملف.
  - زر «قواعد الضريبة» ← يفتح `PayrollTaxRulesModal`.
  - زر «اعتماد الكشف» (مسودة) ← اعتماد الدورة (يُعطّل إن وُجد بند بصافي سالب).
  - زر «صرف جماعي» (معتمدة) ← يفتح `PayrollPayoutModal`.
  - زر «إغلاق الفترة» (مصروفة) ← إغلاق الدورة نهائيًا بعد تأكيد.
  - زر «احتساب المسودة» في حالة عدم وجود دورة.
  - زر «قسيمة» على كل بند ← يفتح نافذة طباعة قسيمة الراتب.
  - في قسم «حركات إضافية للموظفين»: أزرار «سلفة»، «مكافأة»، «خصم» لكل موظف ← تفتح `PayrollTransactionModal` مع نوع الحركة.
