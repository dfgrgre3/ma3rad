# توثيق صفحات المبيعات واليوميات والأنشطة الرأسية (Verticals)

هذا الملف يوثّق الصفحات التفاعلية في مسارات المبيعات (`/sales`, `/pos`, `/quotations`, `/orders`, `/returns`)، وصفحات العمليات اليومية (`/daily/*`)، والصفحات الرأسية لكل نشاط (`/restaurant`, `/hospitality`, `/ceramics`, `/education`, `/time-billing`, `/retail`, `/manufacturing`, `/construction-estimate`). كل عنصر تفاعلي (زر، زر أيقونة، تبويب، عنصر قائمة، إجراء داخل نافذة) موثّق بتسميته الفعلية وما يفعله.

> ملاحظة عامة عن الصلاحيات: أغلب الأزرار مقيدة بصلاحيات مثل `sales.create`، `sales.void`، `customers.payment`، `purchases.create`، `orders.create`، `manufacturing.manage`، `projects.update`... والأزرار غير المصرّح بها لا تظهر للمستخدم.

## `/pos` — نقطة البيع السريعة (POS)

- **الملف:** `src/pages/sales/pos/PosPage.tsx` (+ `src/pages/sales/pos/components/*` و `src/hooks/pages/sales/pos/usePosView.ts` و `usePosActivityCopy.ts`)
- **الوصف:** شاشة الكاشير الرئيسية: شبكة منتجات مع بحث وباركود وفلاتر، سلة مشتريات، لوحة دفع بطرق دفع متعددة، ورديات كاشير، طلبات معلّقة، حاسبة مقاييسات، وعميل نقدي/مسجّل.
- **العناصر التفاعلية:**
  - **شريط أدوات علوي (`PosToolbar` / `PosToolbarActions` / `PosToolbarMoreMenu`):**
    - زر «فتح وردية» (أيقونة Unlock) ← يفتح نافذة «فتح وردية كاشير» لاختيار الخزينة والرصيد الافتتاحي، يظهر فقط بدون وردية مفتوحة.
    - زر «إغلاق الوردية» (أيقونة Lock) ← يفتح نافذة «إقفال الوردية ومطابقة الصندوق».
    - زر المعلّقات `F10` بعنوان «الطلبات المعلّقة» وعرض العدد ← يفتح نافذة «الطلبات المعلّقة».
    - زر «الاختصارات» `F1` ← يفتح نافذة «اختصارات لوحة المفاتيح» (F2 بحث، F9 اعتماد، F10 معلّقات...).
    - زر «المزيد» ← قائمة منسدلة فيها:
      - «تبديل المستخدم (PIN)» / «المستخدم: …» ← يفتح نافذة إدخال PIN (4-8 أرقام) لتبديل موظف البيع أثناء الوردية.
      - «العودة للمستخدم الأصلي» ← يعيد العملية للمستخدم المسجّل بعد التبديل.
      - «شاشة {displayTitle}» ← يفتح شاشة العميل/العرض للعميل.
      - «وضع شاشة اللمس» ← يبدّل وضع اللمس (مفعل/متوقف).
      - «الخزينة وصناديق الكاش» ← ينقل إلى `/cashboxes`.
  - **شريط «البيع المخفض»** (يظهر عند وجود مخزون فرز ثانٍ/بواقي):
    - زر «البيع المخفض (N)» ← يفتح نافذة الأصناف المخفضة؛ داخلها زر «أضف للسلة» لكل صنف و«إغلاق».
  - **فلاتر الكتالوج (`PosCatalogFilters`):**
    - حقل بحث «امسح الباركود أو ابحث بالاسم / SKU / الكود الداخلي / المقاس… (F2)» ← بحث فوري وباركود.
    - قائمة «المخزن: …» ← تصفية حسب المخزن.
    - قائمة «ترتيب: الاسم / الأرخص أولاً / الأغلى أولاً / الأكثر رصيداً».
    - زر «فلاتر» ← يفتح/يطوي الفلاتر المتقدمة: فلتر الماركة، فلتر الفرز، فلتر المقاس، فلتر اللون، وتبديل «المتوفر فقط».
    - زر «حاسبة المقايسة» (يظهر للأنشطة السيراميكية) ← يفتح نافذة حاسبة المقايسة.
    - صف التصنيفات: زر «الكل» + أزرار كل فئة منتج ← تصفية حسب الفئة.
    - زر «مسح الفلاتر» (عند وجود فلاتر نشطة) ← يعيد تعيين البحث والفلاتر.
  - **شبكة المنتجات (`PosProductGrid`):**
    - تبديل العرض «شبكة» / «جدول» ← يبدّل شكل عرض المنتجات.
    - «تحديد المنتجات المعروضة» / «إلغاء التحديد» / «أضف المحدد (N)» ← تحديد متعدد وإضافة دفعة واحدة للسلة.
    - النقر على بطاقة/صف منتج ← يضيف الصنف للسلة؛ النقر على صنف منخفض المخزون يفتح نافذة «تحذير: خلط نغمات ألوان مختلفة» مع «متابعة على مسؤوليتي» و«إلغاء — مراجعة الكميات».
    - «عرض المزيد / تحميل المزيد من المنتجات» ← ترقيم المنتجات.
  - **لوحة السلة (`PosCartPanel` / `CartLine`):**
    - زر حذف الصنف (أيقونة X، عنوان «حذف من السلة (Delete)») ← يزيل السطر ويعرض إشعار تراجع «… — تراجع».
    - أزرار الوحدة (عند تعدد وحدات البيع) ← تبديل وحدة السطر.
    - أزرار الكمية −/+ وتعديل الكمية يدوياً.
    - تعديل سعر السطر.
    - زر الخصم لكل سطر.
    - قائمة «تثبيت / اختيار مستوى السعر» ← اختيار مستوى سعر للعميل.
    - محدد العميل: بحث، فتح قائمة العملاء، العملاء الأخيرة، «تحميل المزيد»، زر مسح العميل «إلغاء اختيار العميل والعودة للبيع النقدي»، وزر «إضافة عميل سريع».
  - **لوحة الدفع (`PosCheckoutPanel`):**
    - أزرار خصم الفاتورة `%` و«ج.م» + نسب سريعة `5%` `10%` `15%` `25%`.
    - أزرار طرق الدفع: «نقدي»، «بطاقة»، «تحويل بنكي»، «شيك»، «آجل»، «دفع مختلط» (تظهر حسب الإعداد/الصلاحيات).
    - قائمة الحساب البنكي عند التحويل البنكي.
    - في «دفع مختلط»: حقول مبالغ لكل وسيلة + زر ملء المتبقي.
    - زر «تطبيق النقاط» ← تطبيق نقاط الولاء على الفاتورة.
    - زر «تعليق» ← يحفظ السلة كطلب معلّق.
    - زر «إفراغ» ← مسح السلة.
    - زر «مقايسة» ← يفتح حاسبة المقايسة داخل POS.
    - زر «اعتماد وحفظ الفاتورة (F9)» ← يخصم المخزون ويسجل الفاتورة؛ أثناء الحفظ يظهر «جاري الحفظ والخصم من المخزن...».
  - **نافذة نجاح الفاتورة:** «إيصال حراري»، «معاينة وطباعة»، «إغلاق»، و«إلغاء هذه الفاتورة» (شرطية — تتطلب اعتماد مدير).
  - **نافذة «الطلبات المعلّقة»:** زر «استرجاع» لكل طلب معلّق + زر حذف (أيقونة سلة).
  - **نافذة «إضافة عميل سريع»:** حقول العميل + زر «حفظ واختيار العميل».
  - **نافذة «فتح وردية كاشير»:** اختيار الخزينة والرصيد الافتتاحي + زر «فتح الوردية».
  - **نافذة «إقفال الوردية ومطابقة الصندوق»:** إدخال الرصيد الفعلي + زر «تأكيد الرصيد المحسوب وإغلاق الوردية» + زر «طباعة تقرير Z (ملخص الوردية)».
  - **نافذة «اعتماد مدير»:** اسم مستخدم + كلمة مرور + «تأكيد»/«إلغاء» (لإلغاء فاتورة).
  - **نافذة «تبديل المستخدم (PIN)»:** حقل PIN + «تأكيد»/«إلغاء».
  - **نافذة حاسبة المقايسة (`CeramicCalculatorModal`):** حساب م²/كرتونة/قطع وإضافة الناتج للسلة.
  - **نافذة الأصناف المخفضة:** قائمة الأصناف + «أضف للسلة»/«إغلاق».
  - **نافذة اختيار العميل (`PosCustomerSelectionDialog`):** بحث، تحديث، اختيار عميل، ترقيم.
  - **شريط سفلي للجوال:** زر «السلة · N أصناف — الإجمالي» يفتح لوحة السلة على الشاشات الصغيرة.

## `/sales` — مركز المبيعات: فواتير المبيعات (Sales Hub)

- **الملف:** `src/pages/sales/sales-hub/SalesHubPage.tsx` (التبويب `invoices` يعرض `src/components/sales/SalesView.tsx`)
- **الوصف:** سجل فواتير المبيعات مع بحث وفلاتر، وتصدير، وفتح تفاصيل الفاتورة (معاينة/طباعة/تحصيل/مرتجع/إلغاء). التبويبات تتبع الصلاحيات.
- **العناصر التفاعلية:**
  - **تبويبات الـ Hub** (`WorkspaceHub`): «فواتير المبيعات»، «تحليلات المبيعات»، «دورة الفاتورة»، «كشف حساب عميل»، «الطلبات والعربون»، «خدمة ما بعد البيع»، «عروض الأسعار»، «الطلبات»، «المرتجعات»، «الفاتورة الإلكترونية» — كل تبويب ينقل للمسار المقابل ويُخفى حسب الصلاحية.
  - **أزرار الرأس:**
    - «جدول بيانات» ← تصدير Excel (صلاحية `sales.export`).
    - «مستند» ← تصدير PDF/مستند.
    - «فاتورة جديدة (POS)» ← ينقل إلى `/pos`.
  - **الفلاتر:** بحث برقم الفاتورة/العميل/الهاتف، حالة السداد («كل حالات السداد / مسددة بالكامل / مسدد جزء / آجل / غير مسدد»)، حالة الفاتورة («الفواتير المكتملة / الملغاة / الكل»)، العملاء، المخازن، نطاق تاريخ.
  - **الفترات السريعة:** «اليوم»، «أمس»، «آخر 7 أيام»، «هذا الشهر»، «مسح التاريخ»، «مسح كل الفلاتر».
  - **زر «تحديث»** ← إعادة تحميل القائمة.
  - **إجراءات كل فاتورة (أيقونات):**
    - «معاينة الفاتورة» (Eye) ← نافذة معاينة المستند.
    - «تفاصيل الفاتورة» (Info) ← نافذة تفاصيل الفاتورة.
    - «طباعة A4» (Printer) ← طباعة فاتورة A4.
    - «طباعة إيصال حراري» (Receipt) ← طباعة إيصال حراري.
    - «تحصيل دفعة» (Wallet) ← نافذة تحصيل دفعة (يظهر عند وجود متبقٍ).
    - «مرتجع مبيعات» (RotateCcw) ← ينقل لصفحة المرتجعات مع الفاتورة (صلاحية مرتجع).
  - **نافذة تفاصيل الفاتورة (`SalesModals`):** بنود الأصناف، الملخص المالي، سندات التحصيل؛ أزرار: «معاينة الفاتورة»، «طباعة A4»، «إيصال حراري»، «كشف حساب العميل» (صلاحية)، «مرتجع مبيعات»، «تحصيل دفعة»، «إلغاء الفاتورة».
  - **نافذة تحصيل دفعة:** المبلغ، طريقة الدفع (نقدي/بطاقة/تحويل بنكي/شيك)، الحساب البنكي المستلم، ملاحظات + «تسجيل التحصيل»/«إلغاء».
  - **نافذة إلغاء الفاتورة:** سبب الإلغاء + «رجوع» + زر تأكيد الإلغاء.

## `/sales/orders-deposits` — الطلبات والعربونات

- **الملف:** `src/pages/sales/sales-orders-deposits/SalesOrdersDepositsPage.tsx` → `src/pages/sales/reservations/ReservationsDepositPage.tsx` (mode="sales") + `ReservationsToolbar*.tsx`, `OrdersDepositsTable.tsx`, `DepositModal.tsx`, `ReservationStatsCards.tsx`
- **الوصف:** طلبات العملاء والحجوزات مع عربونات/دفعات مقدمة، وتحويل الطلب لفاتورة مع خصم العربون. (في وضع المخزون يظهر تبويب «سجل حجز الأصناف بالمخازن» وأزرار إضافية.)
- **العناصر التفاعلية:**
  - **رأس الصفحة:** عنوان «إدارة الحجوزات والعربونات» + (في وضع المخزون فقط) «تحديث الصلاحيات» (فحص الحجوزات المنتهية) و«حجز كمية بضاعة يدوياً».
  - **تبويبات `ReservationsToolbar`:** «طلبات الحجز والعربونات (N)» و(وضع المخزون) «سجل حجز الأصناف بالمخازن (N)».
  - **بحث** برقم/عميل/صنف + قائمة حالة («جميع الحالات»، طلبات: قيد الانتظار/مؤكد/قيد التجهيز/مكتمل ومفوتر/ملغي؛ حجوزات: نشط/مُفرج/مُنفّذ/منتهي) + زر «تحديث البيانات» (RefreshCw).
  - **بطاقات إحصائية:** عدد الحجوزات النشطة، الكمية المحجوزة، الطلبات المعلقة، إجمالي العربونات المحصلة.
  - **جدول الطلبات (`OrdersDepositsTable`):**
    - زر «عربون» (أيقونة DollarSign، يظهر لصلاحية إنشاء وطلب غير مكتمل/ملغي) ← يفتح نافذة «تسجيل دفعة / عربون» (`DepositModal`).
    - زر «فوترة» (أيقونة ArrowUpRight، يظهر لصلاحية فوترة) ← يصدر فاتورة مبيعات من الطلب ويخصم العربون المسدد.
    - في سجل العربونات: زر «رد العربون» ← استرداد العربون.
  - **جدول حجوزات المخزون (`StockReservationsTable`، وضع المخزون):** زر «صرف» (صرف وتنفيذ الحجز) و«إلغاء الحجز» (فك الحجز).
  - **نافذة `DepositModal` (عربون/دفعة):** المبلغ، طريقة الدفع («نقدي (خزينة المعرض)»، «بطاقة بنكية / فيزا»، «شيك»، «تحويل بنكي / إنستاباي»)، الحساب البنكي عند التحويل، ملاحظات/رقم مرجع + «إلغاء» و«تأكيد وحفظ العربون».
  - **نافذة `NewReservationModal` (حجز يدوي، وضع المخزون):** صنف/كمية/مدة/مصدر الحجز («حجز يدوي مباشر»، «مرتبط بطلب عميل»، «مرتبط بعرض سعر»، «مرتبط بمشروع») + «إلغاء» و«تأكيد حجز الكمية».

## `/sales/cycle` — دورة الفاتورة

- **الملف:** `src/pages/sales/invoice-cycle/InvoiceCyclePage.tsx`
- **الوصف:** تتبع دورة حياة الفاتورة عبر المراحل: مسودة ← اعتماد السعر ← حجز الكمية ← إصدار الفاتورة ← دفع جزئي ← التحصيل ← الصرف والتسليم، مع درج تفاصيل لكل فاتورة.
- **العناصر التفاعلية:**
  - بطاقات المراحل السبع (نقر يبدّل التصفية عليها، والنقر مجددًا يرجع «الكل»).
  - بحث برقم الفاتورة/العميل + فلترا «حالة السداد» (مسددة/جزئية/غير مسددة) و«حالة الفاتورة» (مكتملة/معلقة/مسودة/ملغاة).
  - زر «تحديث» (RefreshCw) + زر تصدير مستند/Excel.
  - النقر على صف الفاتورة ← فتح درج التفاصيل.
  - **درج تفاصيل الفاتورة:** «طباعة»، «تحصيل دفعة» (يفتح نافذة تحصيل)، «إغلاق/خلفية».
  - **نافذة «تسجيل تحصيل»:** المبلغ المحصل، طريقة الدفع («نقدي»/«بطاقة»/«تحويل بنكي» — الأخير يتطلب حسابًا بنكيًا)، ملاحظات + «تأكيد التحصيل»/«إلغاء».
  - ترقيم الصفحات (السابق/التالي).

## `/manufacturing` — التصنيع

- **الملف:** `src/pages/manufacturing/manufacturing/ManufacturingPage.tsx` + `tabs/*.tsx` (12 تبويبًا)
- **الوصف:** أوامر إنتاج، أرضية إنتاج، تخطيط مواد MRP، مراكز عمل، قوائم مواد BOM، جودة، صيانة، سلامة، تكاليف وسعة، تتبع.
- **العناصر التفاعلية:**
  - زر «تحديث» (أيقونة) في الرأس.
  - **التبويبات:** «نظرة عامة»، «أوامر الإنتاج»، «أرضية الإنتاج»، «من أوامر البيع»، «تخطيط المواد»، «مراكز العمل»، «قوائم المواد»، «سلسلة التتبع»، «الجودة»، «الصيانة»، «السلامة»، «التكاليف والسعة».
  - **نظرة عامة:** تنبيهات نواقص المواد + زر «إنشاء طلبات شراء (N)» من اقتراحات النقص.
  - **أوامر الإنتاج:** فلاتر حالة (الكل + كل حالة) + «تصدير Excel» + «إنشاء أمر إنتاج»؛ لكل أمر: «تعديل»، «إصدار»/«إلغاء»/«بدء» حسب الحالة، «طلب اعتماد»/«اعتماد»/«رفض»، «ربط بالوردية»/«بدء بالوردية»، «استلام إنتاج»؛ لكل مادة: «صرف»؛ لكل عملية: «بدء»/«تخطي»/«إكمال»/«توقف»؛ نافذة إجراء موحّدة («إلغاء» + تأكيد الإجراء).
  - **أرضية الإنتاج:** «بدء» الأمر، «استلام»، لكل عملية «بدء»/«تخطي»/«إكمال»/«توقف»، لكل مادة «صرف»، و«توقف» عام للأمر؛ نافذة إجراء (كمية/سبب).
  - **من أوامر البيع:** تحويل بنود أوامر البيع المعتمدة لأوامر إنتاج (زر إنشاء لكل صف).
  - **تخطيط المواد (MRP):** «إنشاء أوامر الإنتاج المخططة» و«إنشاء طلبات الشراء من خطة MRP»؛ جدول الإنتاج المخطط واحتياجات المواد؛ «خطة الإنتاج الرئيسية MPS»: نموذج إضافة + «إلغاء» لكل إدخال؛ «MRP مُدرَّج زمنياً».
  - **مراكز العمل:** نموذج إضافة مركز، «تعديل» (قلم) و«تفعيل/إيقاف» لكل مركز؛ نافذة تعديل + «حفظ»/«إلغاء».
  - **قوائم المواد (BOM):** نموذج BOM جديد (+إضافة مكوّن/+إضافة عملية/حذف) + حفظ؛ لكل BOM: «تعديل»، «توجيه» (عمليات التوجيه)، «تفعيل»، «أرشفة».
  - **سلسلة التتبع:** تتبع أمامي (من أمر إنتاج) وزر «تشغيل التتبع»؛ تتبع عكسي (من خامة/مورد/تشغيلة) وزر «تشغيل».
  - **الجودة:** «تسجيل فحص» جديد (+عيوب)، «تعديل» فحص، «تسجيل» القرار (disposition)، «إعادة عمل»؛ أكواد العيوب: «+ إضافة عيب» في النماذج، «إيقاف» لكل كود، نموذج كود عيب جديد.
  - **الصيانة:** حفظ مواعيد، «تسجيل توقف إنتاج» (نافذة + تأكيد)، نموذج صيانة/أمر عمل جديد.
  - **السلامة (HSE):** أقسام فرعية (حوادث/تصاريح/فحوصات/تدريبات) + «تسجيل الحادث»، «طلب التصريح»، «تسجيل الفحص»، «تسجيل التدريب»؛ لكل حادث/تصريح: تحديث حالة («بدء التحقيق»/إغلاق)، «اعتماد»/«إلغاء» تصريح.
  - **التكاليف والسعة:** «تصدير Excel»، «محاكاة» سيناريو تكلفة + «مسح»؛ تقارير أوامر/عمالة/صيانة/OEE/كفاءة مراكز العمل.
