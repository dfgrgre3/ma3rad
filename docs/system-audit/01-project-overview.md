## 1. الهدف من النظام

نظام إدارة موارد مؤسسات (ERP) موجّه أساساً لنشاط السيراميك والأدوات الصحية، مع دعم أنواع أنشطة أخرى (تجاري/خدمي/مطاعم) من خلال ملفات أعمال (Business Profiles) ووحدات قابلة للتفعيل.

يغطي النظام:

- المبيعات ونقطة البيع (POS) والمرتجعات والاستبدال.
- المشتريات ودورة التوريد الكاملة (طلب شراء ← عرض سعر ← أمر شراء ← استلام ← فاتورة ← مرتجع ← مطالبة مورد).
- المخزون والمستودعات والتحويلات والجرد والتقييم (FIFO) والصلاحية/الدفعات.
- المالية والمحاسبة: دليل الحسابات، القيود المزدوجة، الخزائن، البنوك، الشيكات، الموازنات، الإقفال المالي، الأصول الثابتة.
- العملاء والموردين والشركاء (رأس المال، الملكية، الأرباح، المسحوبات، القروض).
- شؤون الموظفين والرواتب والحضور والإجازات والعقود والمستندات والتوظيف.
- التصنيع (قوائم المواد، أوامر الإنتاج، الجودة، الصيانة).
- المشاريع ومراكز التكلفة والموازنات.
- التقارير ومركز التقارير والتحليلات.
- الإدارة والأمان: المستخدمون، الأدوار، 2FA، سجل التدقيق، النسخ الاحتياطي، صحة النظام، الترخيص المركزي.

### طبقات الكود

| المسار | الدور | الحجم التقريبي |
|---|---|---|
| `src/pages/` | 149 مساراً وظيفياً و223 ملف TSX | الجزء الأكبر من الواجهة |
| `src/components/` | مكوّنات مشتركة (جداول، نماذج، حوارات، طباعة) | — |
| `src/services/` | منطق الأعمال والصلاحيات والقيود المحاسبية | ~130 خدمة/جزء |
| `src/database/` | `db.ts` (إدارة SQL.js)، `ledger.ts` (القيد المزدوج)، `migrations*` | 50KB+120KB+25 ملف |
| `electron/` | العملية الرئيسية، IPC، التشفير، النسخ، الطباعة، التحديث | ~5,000 سطر |
| `test/` | 84 ملف اختبار (وحدة/تكامل/أمان/أداء) | 460 اختباراً |

### قواعد معمارية ملحوظة

- **الخدمات هي مصدر الحقيقة:** التحقق من الصلاحيات يتم داخل الخدمة (`PermissionService.require`) وليس في الواجهة فقط.
- **المعاملات الذرية:** العمليات المالية تُنفَّذ عبر `DatabaseManager.executeTransaction`.
- **القيد المزدوج:** كل حركة مالية تُرحَّل عبر `postLedgerEntry` مع عكس عبر `reverseLedgerEntry`.
- **نطاق الفرع/الشركة:** معظم الخدمات تُطبّق `BranchAccessService.sqlScope` و`company_id` على الاستعلامات.
- **سجل تدقيق:** العمليات الحساسة تكتب في `audit_logs` و/أو `domain_events`.

## 4. تشغيل التطبيق

```bash
npm install
npm run dev            # Vite + Electron للتطوير
npm run typecheck      # فحص الأنواع
npm run lint           # ESLint
npm test               # 460 اختباراً
npm run build          # بناء الواجهة
npm run electron:dist  # حزمة Windows
```

بيانات التطبيق على Windows:

- القاعدة: `%APPDATA%\CeramiSysERP\data\ceramisys.sqlite`
- المفتاح: `%APPDATA%\CeramiSysERP\database-key.enc`
- النسخ: `%APPDATA%\CeramiSysERP\backups\`
