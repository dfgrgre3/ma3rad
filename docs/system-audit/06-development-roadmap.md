## معايير الجودة الدائمة (Definition of Done)

أي تغيير جديد لا يُعتبر مكتملاً إلا إذا:

1. مرّ `npm run typecheck`.
2. مرّ `npm run lint` بدون أخطاء جديدة.
3. أُضيف/عُدّل اختبار يغطي السلوك.
4. نجح الاختبار المستهدف ثم الاختبار الكامل.
5. وُثّق في `07-implementation-log.md` (مع السبب والملفات).
6. لم يُغيّر بيانات أو جداول قائمة دون ترحيل موثّق في `11-database-migrations.md`.
