# توثيق صفحات الإعدادات والإدارة

> توثيق لكل العناصر التفاعلية (أزرار، تبويبات، قوائم منسدلة، إجراءات الصفوف والمودالات) في الصفحات المذكورة. الصلاحيات (Permissions) تُذكر مع العناصر عند الحاجة. الحقول النصية العادية لا تُفصّل إلا ضمن مجموعات قابلة للتنفيذ.

## `/settings` — مركز إعدادات النظام

- **الملف:** `src/pages/settings/settings-hub/SettingsHubPage.tsx`
- **الوصف:** الصفحة الرئيسية لكل إعدادات النظام؛ تعرض `AdminSettingsTab` بتبويباته الفرعية وتوجّه لإعدادات الاعتمادات. كما تدعم عرض تبويبات إضافية عبر معاملات الاستعلام `?tab=appConfig` و`?tab=configStudio` و`?tab=approvals` بعد فحص صلاحية الوصول لكل منها.
- **العناصر التفاعلية:**
  - تبويبات `AdminSettingsTab` الداخلية (قائمة ثابتة): «عام»، «الأعمال»، «الهوية والمظهر»، «التخصيص»، «الفاتورة»، «المخزون»، «العمليات»، «الأمان»، «النسخ الاحتياطي» — كل تبويب يبدّل محتوى لوحة الإعدادات دون حفظ فوري؛ التغييرات تُحفظ عبر زر الحفظ في `AdminSettingsTab`.
  - رابط/بطاقة «إعدادات الاعتمادات والموافقات» ← ينقل إلى `/settings/approvals`.
  - تبويب/قسم `appConfig` (عبر `?tab=appConfig`) ← يعرض صفحة «تكوين التطبيق» المضمّنة (انظر قسم `/settings/app-configuration`).
  - تبويب/قسم `configStudio` (عبر `?tab=configStudio`) ← يعرض استوديو التكوين المضمّن (انظر قسم `/settings/configuration-studio`).
  - تبويب/قسم `approvals` (عبر `?tab=approvals`) ← يعرض إعدادات الاعتمادات (انظر `/settings/approvals`).
  - في رأس التحديثات: زر «تحقق من التحديثات» ← يستدعي `window.ceramisys?.updater?.check`.
  - زر «تثبيت وإعادة التشغيل» ← يظهر فقط عند اكتمال التنزيل ويستدعي `window.ceramisys?.updater?.install`؛ يعرض حالات «جارٍ التحقق»، «غير مدعوم»، «متاح/غير متاح»، «جارٍ التنزيل»، «تم التنزيل»، «خطأ».
  - داخل تبويب «الهوية والمظهر» (محرر الاستوديو — `AppearanceCustomizationTab`):
    - زر «استعادة المظهر الافتراضي» ← يعيد إعدادات الواجهة للافتراضي بعد تأكيد `window.confirm`.
    - في «ألوان النظام»: زر «استعادة جميع الألوان الافتراضية» ← يستعيد ألوان النظام؛ والنقر على أي بطاقة لون يفتح محرر الألوان.
    - في «الثيمات الجاهزة»: حقل بحث «ابحث عن اسم الثيم» ومرشحات تصنيف؛ زر «تطبيق الثيم» على كل بطاقة ثيم ← يطبق لوحة ألوان الثيم.
    - في «المحرر المخصص للألوان»: زر «تطبيق الألوان الحالية» ← يطبق الثيم المخصص بعد تحقق نسبة التباين؛ زر «إعادة الافتراضي» ← يستعيد ألوان المحرر؛ أزرار «حفظ الثيم»/«تحديث الثيم» و«نسخ» و«حذف» لإدارة الثيمات المحفوظة؛ ولـكل ثيم محفوظ أزرار «تطبيق»/«تعديل»/«حذف».
    - في «حفظ الثيم المخصص»: حقل «اسم الثيم»، أزرار «حفظ الثيم»/«تحديث الثيم»، «نسخ»، «حذف».
    - في «إعدادات الواجهة»: قوائم منسدلة «نمط الأزرار»، «استدارة الزوايا»، «كثافة الواجهة»، «حجم الخط»، «نوع الخط»، «الوضع» (فاتح/داكن/حسب الجهاز)، «تخطيط التنقل»، «اتجاه الواجهة» — كلها تغيّر مسودة الإعدادات المحفوظة لاحقًا.
    - في نافذة «تخصيص لون النظام» (ColorEditorDialog): زر «إغلاق»/«إلغاء»، زر «نسخ HEX»، زر «استعادة الافتراضي»، زر «تطبيق اللون»، وألوان مقترحة قابلة للنقر.
  - في تبويب «الفاتورة» (محرر الفواتير — `InvoiceTab` ومكوناته):
    - زر «معاينة حيّة للفورم» ← يفتح نافذة معاينة الفاتورة (`InvoicePreviewModal`).
    - زر «استكشاف الطابعات» ← يفحص طابعات ويندوز عبر `PrintService`.
    - بطاقات قوالب الفاتورة (مثل «جدول واضح»، «كلاسيكي رسمي (Classic)»، «عصري حديث (Modern)»، «مدمج واقتصادي (Compact)»، «تفصيلي للمعارض») مع زر معاينة «معاينة هذه الفورما» لكل قالب.
    - في النافذة المنبثقة «معاينة حيّة للفورم والمقاسات»: أزرار فورمات «جدول واضح/كلاسيكي/عصري/مدمج/تفصيلي للمعارض»، أزرار مقاسات «A4/A5/حراري (Thermal)»، زر «اعتماد هذه الفورما الآن» (يحفظ القالب والمقاس كمفضلين)، زر «طباعة تجريبية»، وزر إغلاق «×».
    - داخل «الطابعة لكل مقاس»: زر «تحديث طابعات ويندوز» (إعادة الفحص)، أزرار «تجربة طباعة A4»/«تجربة طباعة A5»/«تجربة طباعة إيصال حراري»، قوائم اختيار الطابعة (A4/A5/حرارية/باركود)، وحقول الطباعة الحرارية: عرض الورق «80مم/58مم»، «كود ترميز الأحرف»، «طريقة التوصيل» (نظام/شبكة TCP 9100).
    - في «تفاصيل الفاتورة»: checkboxes لإظهار/إخفاء الأقسام (العروض، الشحن، طرق الدفع، الملاحظات، شعار الشركة، تفاصيل البنود) وأزرار أسهم «تحريك لأعلى/لأسفل» لترتيب الأقسام الاختيارية؛ زر/حقل «رفع الشعار» أو «تغيير الشعار»؛ قوائم نمط الجدول «كلاسيكي بشبكة حدود (Grid Bordered)»، «عصري بسطور متناوبة (Zebra Striped)»، «مدمج وموفر للورق (Clean Minimal)»؛ وإظهار/ترتيب أعمدة الجدول وأزرار تحريك لأعلى/لأسفل.
    - في «نصوص الترويسة والتذييل وشروط الاسترجاع»: حقول نصية للترويسة والتذييل تُحفظ ضمن مسودة الإعدادات.
  - في تبويب «المخزون» (`InventoryTab`): خيارات طريقة التكلفة «متوسط التكلفة المرجح»، «FIFO (الوارد أولاً يصرف أولاً)»، مفتاح «السماح بالمخزون السالب»، وحد «تنبيه حد المخزون المنخفض».
  - في تبويب «العمليات» (`OperationsTab` + `OperationsPosSection`/`OperationsStockSection`/`OperationsApprovalsSection`):
    - عدد مستويات أسعار البيع: «سعر واحد» حتى «5 أسعار».
    - checkboxes إظهار/إخفاء: طرق الدفع، كود القسيمة، نقاط الولاء، تكرار بنود الفاتورة، حفظ تلقائي لنقطة البيع، بحث متعدد الاختيار، البيع بالسالب، المبيعات غير الكافية كـ«محجوز»، قفل كمية المحجوزة للبيع، منع بيع التصريح بدون مخزون، منع تصريح تسليم بالسالب، البيع بالسالب لحاملي الصلاحية، خصم البند، اشتراط الفاتورة/العميل للمرتجع، فواتير جديدة تحت التصريح، ضريبة القيمة المضافة على رسوم التوصيل، حد خصم أمين الصندوق، اعتماد المدير عن بعد، اعتماد تسوية المخزون، اعتماد تغيير السعر.
    - محرر «أسباب حذف البنود» (`ItemRemovalReasonsEditor`): زر «إضافة سبب» (يفتح إدخالًا داخليًا؛ «إضافة» يؤكد وEnter يؤكد وEscape/× يلغي)، وأيقونة X لكل سبب قائم بعنوان «حذف هذا السبب».
  - في تبويب «الأمان» (`SecurityTab`): حقول مهلة الجلسة، حد محاولات الدخول الفاشلة، طول رمز PIN، فاصل النسخ الاحتياطي التلقائي، وcheckboxes للحسابات المسموح لها بالدخول إليها.
  - في تبويب «النسخ الاحتياطي» داخل الإعدادات: إعدادات النسخ الاحتياطي التلقائي وحقوله (تُحفظ مع بقية الإعدادات).
  - في تبويب «الأعمال» (`BusinessTab`): لوحة «الشركات» (`CompaniesPanel`) — زر تحديث «تحديث»، زر «إنشاء شركة» (يفتح نموذجًا بزر «حفظ»)، وأزرار الصف «تعديل/حفظ» و«تعطيل»؛ بالإضافة إلى إجراء «تحميل للمراجعة» لنسخ الإعدادات وإصدارين للمقارنة.
  - زر الحفظ الرئيسي أعلى تبويب الإعدادات («حفظ التغييرات») ← يحفظ مسودة كل التبويبات عبر `AppConfigService`/خدمة الإعدادات.

## `/settings/approvals` — إعدادات الاعتمادات والموافقات

- **الملف:** `src/pages/settings/approval-settings/ApprovalSettingsPage.tsx` (المسار الدقيق قد يكون `src/pages/settings/approvals/ApprovalSettingsPage.tsx` حسب بنية المجلد)
- **الوصف:** إدارة سياسات الاعتماد لكل عملية (خصم، سعر، مرتجع، تسوية مخزون، طلب شراء، مصروف...) عبر `ApprovalPolicyService`؛ يتطلب صلاحية `approvals.settings.manage` وإلا تعرض رسالة رفض وصول.
- **العناصر التفاعلية:**
  - حقل بحث «تصفية العمليات» يطابق التسمية/الفئة/الكود.
  - لكل عملية: اختيار نمط السياسة (منها «ممنوع»)، قيمة الحد الأدنى، عدد الموافقات المطلوبة، نمط الاعتماد «معتمد واحد»/«موافقات متعددة»، نطاق التطبيق «الفرع»/«المستودع»/«عام»، ساعات الانتهاء، checkbox «السماح لمنشئ الطلب باعتماده»، checkboxes لأدوار المنفذين والمعتمدين.
  - زر «حفظ هذه السياسة» على كل عملية ← يستدعي `ApprovalPolicyService.setPolicy`؛ يتحول إلى «جارٍ الحفظ…» أثناء الحفظ.

## `/settings/license-mode` — وضع الترخيص

- **الملف:** `src/pages/settings/license-mode/LicenseModeSettingsPage.tsx`
- **الوصف:** اختيار نمط الترخيص (حسابي مقابل جهاز/عتادي) والتحقق منه عبر `window.ceramisys?.license`؛ يتطلب `admin.license.manage` أو `settings.license_mode.manage`.
- **العناصر التفاعلية:**
  - خيارا الوضع: «حسابي» (account) و«عتادي» (hardware).
  - عند تغيير الوضع تظهر نافذة «تأكيد صلاحية المسؤول» بأزرار «إلغاء» و«تأكيد»؛ «تأكيد» يتحقق من اسم مستخدم وكلمة مرور المدير ثم يستدعي `window.ceramisys?.license?.setMode`، ويُمسح حقل كلمة المرور بعد النجاح.
  - تحميل الوضع الحالي عبر `window.ceramisys?.license?.getMode` عند الفتح.

## `/settings/app-configuration` — تكوين التطبيق (تحويل)

- **الملف:** `src/pages/settings/app-configuration/AppConfigurationPage.tsx`
- **الوصف:** المسار `/settings/app-configuration` يعيد التوجيه إلى `/settings?tab=appConfig`؛ والمكوّن نفسه هو تبويب «تكوين التطبيق» داخل مركز الإعدادات، ويعمل كإدارة تكوين ديناميكية (صفحات، أقسام، حقول، نصوص، سياسات وترقيم، قوالب طباعة، وحدات، نطاقات، سجل إصدارات) عبر `AppConfigService`/`ModuleRegistryService`/`ActionRegistryService`/`FeatureService`/`TerminologyService`.
- **العناصر التفاعلية:**
  - تبويبات داخلية: «نظرة عامة»، «الصفحات»، «الأقسام»، «الحقول»، «النصوص»، «السياسات والترقيم»، «السجل والإصدارات».
  - في «نظرة عامة»: أزرار «تصدير JSON»، «إعادة الضبط الكامل»، «استيراد من ملف» (نافذة ملف + `FileReader` بحد أقصى للطول).
  - في «الصفحات»: بحث، مفاتيح إظهار/إخفاء الصفحة، تعديل التسمية والترتيب، وإعدادات خاصة بالمسار؛ الصفحات المخفية تُحجب ومساراتها تُمنع عبر محرك التكوين الديناميكي.
  - في «الأقسام» و«الحقول» و«النصوص»: أزرار/نماذج إضافة وتعديل وحذف عناصر التكوين؛ زر «إضافة قاعدة نص»؛ زر «إضافة» في نموذج الهدف اليدوي.
  - في «السياسات والترقيم»: قيم السياسات المركزية، قوالب الترقيم وقوالب الطباعة، مفاتيح تفعيل/تعطيل الوحدات (تعطيل وحدة لا يحذف بياناتها)، وأزرار «افتراضي» لإزالة تجاوزات الترقيم واستعادة السلوك الافتراضي.
  - في «السجل والإصدارات»: قائمة إصدارات التكوين وزر «استعادة» لكل إصدار.
  - الحالة للقراءة فقط أو انعدام صلاحية التحديث `settings.update` يخفي/يعطل إجراءات الكتابة.

## `/settings/configuration-studio` — استوديو التكوين (تحويل)

- **الملف:** `src/pages/settings/configuration-studio/ConfigurationStudioPage.tsx`
- **الوصف:** المسار `/settings/configuration-studio` يعيد التوجيه إلى `/settings?tab=configStudio`؛ والمكوّن هو تبويب «استوديو التكوين» داخل مركز الإعدادات، لإدارة الأزرار والإجراءات، الميزات والاشتراكات، النطاقات والوراثة، والتشخيصات.
- **العناصر التفاعلية:**
  - تبويبات داخلية: «الأزرار والإجراءات»، «الميزات والاشتراكات»، «النطاقات والوراثة»، «التشخيصات».
  - في «الأزرار والإجراءات»: اختيار إجراء من السجل، تعديل التسمية/الظهور، خيار التأكيد، وزر «تحديث إجراء» للحفظ عبر `ActionRegistryService`.
  - في «الميزات والاشتراكات»: عرض حالة الميزات وتجاوزات الوحدات عبر `FeatureService`.
  - في «النطاقات والوراثة»: اختيار الصفحة/المسار، تفعيل/تعطيل، تجاوز التسمية، وزر «حفظ تجاوز النطاق» لدعم نطاق فرع/مستخدم/عام مع وراثة الإعدادات.
  - في «التشخيصات»: عرض إحصاءات التكوين (القواعد، الإدخالات المخصصة بالنطاق، سلسلة النطاق، الوحدات المفعّلة، عدد الإجراءات والميزات) دون إجراءات كتابة.
  - يتطلب صلاحية `settings.update` للتعديل.

## `/data-import` — مركز استيراد الملفات

- **الملف:** `src/pages/settings/data-import/DataImportPage.tsx`
- **الوصف:** استيراد بيانات من ملفات (جداول بيانات وملفات أخرى مدعومة) إلى كيانات ERP أو أنواع البيانات المرنة؛ يتضمن كشفًا تلقائيًا، معاينة، تحققًا، ربط الأعمدة، معالجة أوراق متعددة، وتقرير أخطاء وتراجع عن الدفعة.
- **العناصر التفاعلية:**
  - رابط/بطاقة للتنقل إلى «إدارة أنواع البيانات المرنة والسجلات» (`/data-import/types`).
  - زر «تنزيل قالب <نوع الكيان>» في رأس الصفحة حسب الكيان المختار.
  - اختيار الكيان: «كشف تلقائي» أو كيان مصرّح به؛ خيار «إنشاء نوع بيانات مرن» لمن يملك `admin.data`؛ استيراد المنتجات يتطلب اختيار مستودع نشط لمخزون أولي.
  - اختيار الملف ثم أزرار سير العمل: المعاينة/التحقق، ربط الأعمدة، ومعالجة أوراق متعددة، وأخيرًا «استيراد N سجل صالح».
  - أزرار «التراجع عن الدفعة» في سجل الاستيراد للعملاء والمنتجات عند توفر الصلاحية.
  - ترتيب الاستيراد الموصى به: التصنيفات، الماركات، المستودعات، العملاء/الموردون/الموظفون، ثم المنتجات.
  - استيراد الكيانات يتطلب صلاحية الكيان؛ الاستيراد الديناميكي يتطلب `admin.data`.

## `/data-import/types` — البيانات الديناميكية (أنواع البيانات المرنة)

- **الملف:** `src/pages/settings/dynamic-data/DynamicDataPage.tsx`
- **الوصف:** إدارة أنواع البيانات المرنة والسجلات الديناميكية؛ إدارة تتطلب `settings.dynamic_data.manage` والتصدير يتطلب `settings.dynamic_data.export` أو الإدارة.
- **العناصر التفاعلية:**
  - رابط/بطاقة للعودة إلى «مركز استيراد الملفات» (`/data-import`).
  - اختيار الكيان/النوع، بحث، فلاتر، فرز، ترقيم صفحات، وزر «تحميل المزيد (...)».
  - زر «تصدير» (XLSX) لتصدير كل السجلات.
  - أزرار الصف: «تعديل» (أيقونة) لفتح محرر السجل، و«حذف» (أيقونة) لحذف السجل.
  - في وضع التعديل: أزرار «حفظ» و«إلغاء».
  - إنشاء حقول ديناميكية وعلاقات بين الأنواع، تعديل السجلات، حذفها، وزر «التراجع عن الدفعة» لتراجع دفعات الاستيراد.

## `/backup` — النسخ الاحتياطي والاستعادة

- **الملف:** `src/pages/settings/backup/BackupPage.tsx`
- **الوصف:** إدارة النسخ الاحتياطية المحلية والأرشيف المركزي عبر `BackupService` و`CentralAppBackupService` و`BackupHistoryTable`؛ الإدارة تتطلب `settings.backup` والاستعادة `settings.backup.restore`.
- **العناصر التفاعلية:**
  - قسم النسخ المحلية: أزرار تصدير نسخة، استيراد/استعادة نسخة، «فتح مجلد نسخ الجهاز»، وتصدير مفتاح الاسترداد.
  - نافذة الاستعادة: حقل «اختيار ملف النسخة الاحتياطية»، زر «فتح مجلد نسخ الجهاز»، زر «تأكيد واستعادة البيانات»، زر «إلغاء»، ومعالجة كلمة مرور/مفتاح الاسترداد.
  - نافذة «تصدير ملف مفتاح الاسترداد»: زر «تشفير وتنزيل المفتاح» (يتطلب كلمة مرور قوية ≥12 حرفًا)، زر «إلغاء».

  - checkbox «تذكرني على هذا الجهاز» ← يحفظ/يمسح بيانات الدخول عبر `window.ceramisys?.credentials` (إلغاء الاختيار يمسح المحفوظ).
  - زر «دخول النظام» / «تحقق ودخول» (عند التحقق الثنائي) / «جارٍ تسجيل الدخول...» ← يستدعي `AuthService.loginAsync`/`loginByPin`/`loginBySecurityKey`.
  - عند تفعيل التحقق الثنائي: حقل «رمز التحقق الثنائي» وزر «العودة إلى بيانات الدخول».
  - حالة القفل المؤقت مع عدّاد تنازلي، وتنبيه «المحاولات المتبقية»، وتنبيه «مفتاح Caps Lock مُفعّل».
  - زر «تهيئة حساب مالك المنصة (لمرة واحدة)» ← يظهر فقط عند عدم تهيئة المالك ويوجّه إلى `#/platform-owner-setup`.
  - `LoginBrandPanel` لا يحتوي عناصر تفاعلية (عرض ثابت فقط).

## `/approvals` — صندوق الموافقات والاعتمادات

- **الملف:** `src/pages/approvals/approvals/ApprovalsPage.tsx`
- **الوصف:** صندوق قرارات الاعتماد (خصم، سعر، مرتجع، تسوية مخزون، طلب شراء، مصروف، إلغاء فاتورة، حد ائتمان...) عبر `ApprovalService`، مع إحصاءات وفلاتر ولوحة تعديلات الفروع المدمجة.
- **العناصر التفاعلية:**
  - زر «طلب اعتماد جديد» (بصلاحية `ui.approvals.inbox.create`) ← يفتح مودالًا بحقول: «نوع الطلب» (قائمة بأنواع `TYPE_CONFIG`)، «العنوان»، «الوصف»، «القيمة المطلوبة (ج)»، «الأولوية» (منخفضة/عادية/عالية/عاجلة)، وأزرار «إلغاء» و«إرسال الطلب».
  - بحث نصي (Enter يعيد التحميل) وقائمة «الحالة» («جميع الحالات»، «قيد الانتظار»، «معتمدة»، «مرفوضة»، «ملغاة»، «منتهية»).
  - لكل طلب معلّق: زر «موافقة» (`ui.approvals.inbox.approve`) يطلب ملاحظات اختيارية عبر `prompt`، زر «رفض» (`...reject`) يطلب سببًا (إلزامي لطلبات تسوية المخزون)، وزر «إلغاء» (`...cancel`) لإلغاء الطلب.
  - لوحة «اعتماد تعديلات الفروع والحسابات المرتبطة» (`SyncChangeApprovalsPanel`) داخل بطاقة؛ قرارات المالك `isOwner` أو المستخدمين حسب `requestedBy`.

## `/documents` و`/contracts` — مركز المستندات والعقود

- **الملف:** `src/pages/documents/documents/DocumentsPage.tsx` (+ `DocumentsDialogs.tsx`، `DocumentsTables_part01/02.tsx`، `documentsShared_part01/02.tsx`؛ ومكوّن مشترك `src/components/documents/DocumentPreviewModal.tsx`)
- **الوصف:** نفس الصفحة تُعرض بنمطين: `/documents` للمستندات و`/contracts` للعقود؛ تتطلب `documents.view`/`contracts.view` وإلا تعرض رسالة رفض وصول. يدعم الإنشاء والتفاصيل والإصدارات والأرشفة وتفعيل/تجديد/فسخ العقود والتصدير.
- **العناصر التفاعلية:**
  - أزرار الرأس: «تحديث» (أيقونة)، «مستند جديد» أو «عقد جديد» (بصلاحية `documents.create`/`contracts.create`)، و«تصدير» (بصلاحية `documents.export`/`contracts.export`) لتصدير السجل إلى Excel.
  - تبويبا «المستندات (N)» و«العقود (N)» للتبديل بين الوضعين.
  - بحث نصي وقائمة «كل الحالات» (حالات المستند: مسودة/نشط/مؤرشف؛ حالات العقد: مسودة/مجدول/ساري/قارب الانتهاء/منتهي/مفسوخ).
  - جدول المستندات: النقر على الصف يفتح مودال التفاصيل؛ جدول العقود يعرض لكل عقد (غير مفسوخ وبصلاحية `contracts.update`) أزرار «تفعيل» (للمسودة)، «تجديد» (يطلب تاريخ النهاية عبر `prompt`)، و«فسخ» (يتطلب `contracts.terminate` ويطلب سببًا عبر `prompt`).
  - في مودال «مستند جديد»: حقول الشركة/العنوان/التصنيف/درجة السرية/تاريخ الانتهاء/الوصف؛ زر «إلغاء» وزر «إنشاء».
  - في مودال تفاصيل المستند (`رقم — عنوان`): أزرار «تفعيل المستند» (من مسودة، `documents.update`)، «أرشفة» (`documents.archive`)، «استعادة» (من مؤرشف)، «إضافة إصدار» (`documents.update`)، ولكل إصدار زر «فتح» يفتح الملف عبر `window.ceramisys?.documents?.openFile`؛ وسجل الأحداث للعرض.
  - في مودال «إصدار جديد»: زر «اختيار ملف» (يستدعي `window.ceramisys?.documents?.importFile`)، حقل اسم الملف/الوصف، ملاحظات، «إلغاء»، «إضافة».
  - في مودال «عقد جديد»: حقول الشركة/العنوان/نوع الطرف/اسم الطرف/البداية/النهاية/القيمة/العملة/تنبيه قبل الانتهاء/مستند مرتبط/تجديد تلقائي/ملاحظات؛ «إلغاء» و«إنشاء».
  - في `DocumentPreviewModal` (مكوّن معاينة مستندات مشترك): زر إغلاق المعاينة (aria-label)، زر «جدول بيانات» للتنزيل Excel، زر «مستند» للتنزيل PDF («تم الحفظ» بعد الحفظ)، زر «طباعة»، زر «واتساب» للمشاركة، وزر إغلاق إضافي.
