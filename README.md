# سيراميسيس ERP — CeramiSys

نظام مكتبي (Electron) لإدارة معارض السيراميك ومواد التشطيب: مبيعات ونقطة بيع،
مخزون ومستودعات، مشتريات، عملاء وموردين، محاسبة وقيود، مشاريع، موارد بشرية،
تصنيع، وتقارير — يعمل بقاعدة بيانات SQLite محلية دون الحاجة إلى خادم.

- **المنصة:** Electron 45 + React 18 + TypeScript + Vite + Tailwind CSS
- **قاعدة البيانات:** SQLite عبر `sql.js` (WASM) مع طبقة هجرات مرقّمة
- **اللغة والاتجاه:** عربي بالكامل (RTL)
- **الإصدار الحالي:** 1.1.3

---

## التشغيل السريع

```bash
npm install

# تطوير الواجهة في المتصفح
npm run dev

# تشغيل تطبيق Electron على نسخة مبنية
npm start

# وضع التطوير داخل Electron (يحتاج Vite يعمل على 5173)
npm run dev        # نافذة أولى
npm run electron:dev
```

### المتطلبات

- Node.js 20 أو أحدث (تم التحقق على Node 24)
- Windows لتوليد مثبّت NSIS (يمكن بناء macOS/Linux من بيئاتها)

### المتغيرات البيئية

انسخ `.env.example` إلى `.env` وعدّل القيم عند الحاجة:

| المتغير | الوصف |
| --- | --- |
| `VITE_DEV_SERVER_URL` | عنوان خادم Vite أثناء التطوير |
| `CENTRAL_API_URL` | عنوان منصة الإدارة/الترخيص المركزية (HTTPS إلزامي) |
| `CERAMISYS_DATA_DIR` | تجاوز مجلد بيانات التطبيق (اختياري) |

## بوابة الجودة

أمر واحد يشغّل كل الفحوص:

```bash
npm run check   # lint + typecheck + test + build
```

أو كل فحص على حدة:

| الأمر | الوظيفة |
| --- | --- |
| `npm run lint` | ESLint على `src` و`electron` و`test` |
| `npm run typecheck` | TypeScript بدون إخراج |
| `npm test` | اختبارات Node (`node:test`) — تشمل قاعدة البيانات والخدمات والأمان |
| `npm run build` | بناء الواجهة إلى `dist/` |
| `npm run e2e` | اختبارات Playwright الشاملة |

> الاختبارات تعمل على قاعدة بيانات مؤقتة ولا تلمس بيانات تثبيت حقيقي.
> مدة التشغيل الكاملة ≈ 3 دقائق.

### قاعدة البيانات والهجرات

- ملف القاعدة: `%APPDATA%\CeramiSysERP\data\ceramisys.sqlite`
- النسخ الاحتياطية: `%APPDATA%\CeramiSysERP\backups`
- الهجرات معرّفة في `src/database/migrations/` بأرقام متسلسلة (حتى `102`)،
  وتُطبَّق تلقائياً عند الإقلاع مع تسجيل النتيجة.
- `DatabaseManager.query` يحوّل أسماء الأعمدة من `snake_case` إلى `camelCase`
  عند القراءة؛ استخدم `camelCase` في نتائج الاستعلامات.

### الصلاحيات

- `PermissionService.can(user, permission)` — يقيّم صلاحية الدور **مع** قيود
  الصفحة/الوحدة المركزية (للاستخدام في الواجهة).
- `PermissionService.hasRoleGrant(user, permission)` — صلاحية الدور فقط
  (للاستخدام داخل الخدمات الخلفية كي لا تتعطّل العمليات بسبب قيود عرض).
- `PermissionService.require(...)` يرمي خطأً عند عدم وجود صلاحية الدور.

## الأمان

راجع **[docs/SECURITY.md](docs/SECURITY.md)** للتفاصيل الكاملة. باختصار:

- `nodeIntegration: false` و`contextIsolation: true` و`sandbox: true`.
- التحقق من مصدر كل استدعاء IPC (إطار رئيسي + عنوان تطبيق مسموح فقط).
- منع الملاحة الداخلية خارج تطبيق التطبيق، وفتح الروابط الخارجية في المتصفح.
- سياسة CSP مُحقَنة وقت البناء (بدون `unsafe-inline` للسكربتات).
- تشفير بيانات الدخول المحفوظة والنسخ الاحتياطية عبر `safeStorage`.
- تدقيق مركزي للعمليات الحساسة (إعدادات، منشأة، فروع، مستخدمون).
- اتصال المنصة المركزية عبر HTTPS فقط (يُسمح بـ HTTP على localhost للتطوير).
- التبعيات: `npm audit --omit=dev` = **0 ثغرات** (react-router 7.18.5+).

## الترخيص المركزي والحدود

التطبيق يعمل محلياً، والمنصة المركزية (اختيارية) تضيف:

| الخدمة | الدور |
| --- | --- |
| `CentralLicenseService` | تفعيل الجهاز، التحقق من الترخيص، نبضة الحياة، جلب التكوين |
| `CentralConfigApplier` | تطبيق نوع النشاط والوحدات المسموحة على الإعدادات |
| `CentralFeaturePermissionService` | إخفاء الصفحات/الأزرار حسب صلاحيات المنصة |
| `CentralUsageLimitService` | فرض حدود (مستخدمون، فروع، مستودعات، موظفون، فواتير) |
| `CentralEstablishmentService` | مزامنة بيانات المنشأة والفروع + تدقيق |

- الترخيص يُتحقق عند الإقلاع وكل 6 ساعات، مع سماحية عمل دون اتصال 14 يوماً.
- التكوين يُحدَّث كل 60 ثانية وعند عودة التركيز للنافذة (بفاصل أدنى 15 ثانية
  لمنع الطلبات المكررة)، وبيانات المنشأة كل ساعة.
- الحدود تُفرض **داخل الخدمات** (`assertWithin`) وليس في الواجهة فقط.
- التكوين المركزي لا يعطّل أبداً العمليات المحلية إذا تعذّر الاتصال.

## استكشاف الأخطاء

| المشكلة | الحل |
| --- | --- |
| نافذة بيضاء بعد الحزم | تأكد أن `npm run build` تمّ قبل الحزم (سكربتات `electron:*` تفعل ذلك) |
| فشل فتح القاعدة | استخدم شاشة الإقلاع: «إعادة المحاولة» ثم «أرشفة القاعدة وبدء قاعدة جديدة» |
| رفض رابط المنصة | يجب أن يبدأ بـ `https://`؛ HTTP مسموح فقط لـ `localhost` |
| فشل اختبارات Electron | شغّل `npm install` كاملاً (يحتاج `sql.js` و`electron`) |
