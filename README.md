# نظام إدارة معرض السيراميك ومواد التشطيب (CeramiSys ERP Desktop)

نظام سطح مكتب احترافي Production-Grade مصمم خصيصاً لإدارة صالات عرض ومخازن السيراميك والبورسلين ومواد البناء والتشطيبات، يعمل بدون إنترنت (Offline-First) بالكامل ومبني على قاعدة بيانات SQLite حقيقية تدعم العمليات المالية والمخزنية المتزامنة (ACID Transactions) وسجلات التدقيق.

---

## 🌟 الميزات الرئيسية للنظام

1. **محرك حسابات السيراميك الدقيق (Ceramic Math Engine):**
   * التحويل التلقائي بين المتر المربع والكرتونة والقطع مع مراعاة المقاسات والسمك ونسب التغطية.
   * التتبع المنفصل لفرز السيراميك (فرز أول، فرز ثاني، فرز ثالث، تجاري) بالباركود والمقاس.
2. **نقطة البيع السريعة (POS):**
   * دعم قارئ الباركود (F2)، الفئات، والمفضلة.
   * الفواتير النقدية، الآجلة، الدفع بالبطاقة، والتقسيط، مع فواتير ضريبية وقوالب طباعة حرارية وA4.
   * نظام مرتجعات المبيعات مع استرجاع الرصيد للمخزن وعكس الأرباح آلياً.
3. **إدارة المخازن المتعددة (Multi-Warehouse):**
   * التحويلات المخزنية بين المعارض والمخازن مع التحقق من الرصيد المتاح.
   * سجل حركات المخزون غير القابل للتعديل المباشر (Immutable Audit Trail).
   * تسويات الجرد الدوري والتوالف مع توثيق الأسباب.
4. **العملاء والموردون والحسابات الآجلة:**
   * كشوف حسابات تفصيلية تفاعلية (مدين / دائن / رصيد تراكمي مستمر).
   * سندات قبض وصرف مع متابعة الحدود الائتمانية وفترات السداد.
5. **الخزينة والورديات والمصروفات:**
   * إدارة ورديات الكاشير (فتح، إغلاق، وحساب العجز والزيادة بين الرصيد الفعلي والمتوقع).
   * تسجيل سندات صرف المصروفات الإدارية والتشغيلية وخصمها من الخزينة.
6. **لوحة المعلومات والتقارير المالية (Real Dashboard & Reports):**
   * كافة الإحصائيات والرسوم البيانية مشتقة 100% من قاعدة البيانات الحقيقية.
   * حساب تكلفة البضاعة المباعة (COGS) والأرباح الصافية الحقيقية.
7. **الأمان والنسخ الاحتياطي:**
   * إدارة المستخدمين والصلاحيات وتشفير كلمات المرور (Bcrypt).
   * تصدير واستعادة النسخ الاحتياطية لقاعدة بيانات SQLite بضغطة زر.

## 🚀 تشغيل النظام (Getting Started)

### 1. تشغيل بيئة التطوير:
```bash
npm run dev
```
افتح المتصفح أو نافذة Electron على: `http://localhost:5173`

### 2. بيانات الدخول الافتراضية لمدير النظام:
* **اسم المستخدم:** `admin`
* **كلمة المرور:** `admin123`
* **رمز PIN السريع:** `1234`
